# Руководство пользователя ChooChooTracker

> Русский перевод [`docs/USER_MANUAL.md`](../USER_MANUAL.md), выполненный по английской версии на коммите `7c3ed6f`. При расхождениях верна английская версия.
>
> **Соглашения.** Интерфейс приложения остаётся на английском. Поэтому названия экранов, меню, полей и кнопок (Song, Chain, Phrase, Instrument, Table, Mixer, **Settings**, **EDIT**, **OPT**, **SELECT**...), коды FX (`HOP`, `TBX`, `M1A`...), названия модулей и движков (ADSR, LFO, Braids, Plaits...) и расширения файлов оставлены без перевода, чтобы вы узнавали их на экране.

ChooChooTracker - это музыкальный трекер на 8 дорожек для портативных консолей.

Он повторяет классический рабочий процесс и навигацию LSDj и предлагает несколько вариантов звукового дизайна:

- эмуляция чипа AY
- осцилляторы Mutable Instruments Braids, Plaits и Plaits-Alt с многорежимным фильтром
- PCM-сэмплы, однопериодные волновые формы и осцилляторы с волновыми таблицами, с многорежимным фильтром
- aChChid - универсальный acid-синтезатор на основе Open303
- Bogie - встроенный синтезатор ударных на 12 моделей с многорежимным фильтром
- MME - синтезатор с двумя осцилляторами и множественной модуляцией, с многорежимным фильтром
- Sintered - встроенный экспериментальный цифровой синтезатор ударных на шесть моделей

## 1. Установка и файлы

### ArkOS / PortMaster

Установите `choochootracker.zip` через PortMaster или скопируйте распакованный пакет в каталог `ports` консоли. Запустите **ChooChooTracker** из меню Ports.

### Miyoo Mini / Mini Plus (Onion OS)

Распакуйте архив MiyooPorts в корень SD-карты так, чтобы его папки `Roms/PORTS/` слились с уже существующими папками Onion. Запустите **ChooChooTracker** из меню Ports после обновления коллекции. Перед заменой существующей установки сделайте резервную копию папки `projects/` приложения.

### Windows

Запустите `choochootracker.exe`, положив `SDL2.dll` и `libwinpthread-1.dll` в тот же каталог.
Нажмите **ALT + ENTER**, чтобы переключить полноэкранный режим. Размер окна можно менять; изображение
масштабируется с сохранением исходного соотношения сторон.

### Web

Страница в браузере следует активной теме трекера. Сохранённые настройки, включая
пользовательские назначения клавиш, подтверждённые кнопкой **Done**, сразу записываются в
хранилище этого браузера. После блокировки экрана или переключения приложений коснитесь любого элемента управления, чтобы при необходимости
восстановить звук. **Restart audio** заново открывает аудиовыход, не теряя
проект. **Reload app** сохраняет текущую работу в **Continue**, сохраняет настройки
и ждёт хранилище браузера перед перезагрузкой; если сохранение завершилось ошибкой или превысило время ожидания,
перезагрузка отменяется. Используйте **Download .cct** для переносимой резервной копии. Хранилище браузера
можно очистить независимо, а восстановление маршрутизации контроллеров и звука в iOS
не гарантируется.

Браузерная версия обновляет изображение примерно 30 раз в секунду и использует фиксированный
аудиобуфер в 1024 кадра, чтобы оставить звуку больше времени между вызовами. Старые сохранённые
настройки буфера корректируются автоматически; проекты и остальные настройки
сохраняются. Опрос ввода и таймеры приложения работают в обычном ритме.

## 2. Управление

ChooChooTracker лучше всего работает с геймпадом, у которого есть крестовина, 2 аналоговых стика и 7 кнопок.

| Логический элемент управления | По умолчанию на портативной консоли | По умолчанию в Windows |
|---|---|---|
| **[LEFT/RIGHT/UP/DOWN]** | крестовина | клавиши-стрелки |
| **EDIT** | A | X |
| **OPT** | B | Z |
| **PLAY** | Start | Пробел |
| **SELECT** | Select | Shift |
| Оси модуляции | левый и правый стики | стики геймпада |
| **STICK LIVE** | L1 | Q |
| **MOTION RECORD** | L2 | W |
| **MOTION ERASE** | R2 | E |

Назначения можно изменить в **Settings > Key mapping**. В PortMaster отпустите
кнопку, которой вы выбирали назначение, прежде чем нажимать новую кнопку. Сохраните
переназначение кнопкой **Done**, затем отпустите кнопку, прежде чем продолжить работу в Settings.
Настольные раскладки по умолчанию используют QWERTZ только для регионов с QWERTZ; польские клавиатуры
сохраняют стандартные значения QWERTY.

Пользователи Windows, веба и Android тоже могут использовать геймпад. В Android
сенсорное управление появляется автоматически, если геймпад не подключён: в портретной ориентации
оно располагается под трекером - квадратная крестовина, элементы A/EDIT, B/OPT, START/PLAY и
SELECT/SHIFT, а затем отдельная секция Live/Motion с двумя стиками модуляции
и кратковременными кнопками REC/DEL. В ландшафтной ориентации крестовина остаётся слева,
а кнопки действий - справа. Проекты и сэмплы Android остаются приватными для
приложения; для импорта проектов `.cct` и сэмплов `.wav`
и для выбора места сохранения экспорта WAV используйте системный выбор файлов Android.

### Навигация

- Используйте **[UP/DOWN/LEFT/RIGHT]**, чтобы перемещать курсор.
- Удерживайте **SELECT + [DIRECTION]**, чтобы переходить между экранами.
- **SELECT + [LEFT/RIGHT]** также выводит со вспомогательных страниц на соседний экран MSCPIT,
  как Instrument Pool: Project/Settings (включая подменю Settings)
  ведут к Mixer/Chain; Groove - к Chain/Instrument; Modulation/Insert FX - к
  Phrase/Table; AY Wavetable - к Instrument/Table. У левого края Reverb/Delay
  возвращаются в Mixer по SELECT + LEFT. Существующая вертикальная навигация не меняется.
- Удерживайте **OPT + [DIRECTION]** для навигации, специфичной для экрана.
- На значении используйте **EDIT + [LEFT/RIGHT]** для точных изменений или **EDIT + [UP/DOWN]** для грубых.
- На **Destination** модуляции **LEFT/RIGHT** напрямую перебирает доступные назначения; коснитесь **EDIT**, чтобы открыть сгруппированное меню.
- Коснитесь **EDIT**, чтобы ввести значение или выполнить команду.
- Дважды коснитесь **EDIT**, чтобы создать новую цепочку, фразу или инструмент, где это поддерживается.
- Удержание направления повторяет его после задержки, настроенной в Settings.

### Выделение и буфер обмена

- **SELECT + OPT** включает режим выделения и перебирает полезные диапазоны выделения.
- Используйте **[DIRECTION]**, чтобы расширить диапазон.
- **OPT** копирует выделение.
- **OPT + EDIT** вырезает его.
- **SELECT + EDIT** вставляет.
- **EDIT + [DIRECTION]** редактирует выделенные ячейки вместе.

На экране Phrase при активном выделении колонку нот можно заполнить
ритмическими рисунками:

- **OPT + LEFT** заполняет ячейки нот выделения фиксированным 16-шаговым рисунком
  и при каждом нажатии переходит к следующему рисунку. После последнего рисунка
  ноты стираются, и цикл начинается заново. Рисунки привязаны к абсолютным
  строкам фразы, поэтому частичное выделение получает только те шаги, которые в него попадают.
- **OPT + RIGHT** заполняет ячейки нот выделения случайным рисунком из
  3-8 нот (7 и 8 выпадают реже), бесконечно повторяя цикл, пока удерживается
  **OPT**.
- **OPT + UP** видоизменяет ноты, уже стоящие в выделении: при каждом нажатии
  выбираются 1-3 из них, и каждая сдвигается на случайную величину в пределах октавы
  (малые сдвиги вероятнее крайних). При активном **Note Lock**
  сдвинутые ноты возвращаются в гамму; инструменты Sampler с включённым
  **Slice** остаются хроматическими. Ничего не стирается: 8-е нажатие восстанавливает
  ноты, которые были в выделении в начале цикла, после чего цикл начинается заново.
- **OPT + UP** на выделении, охватывающем только колонку громкости (без нот,
  инструментов и ячеек FX), вместо видоизменения рандомизирует velocity: первое
  нажатие применяет рисунок Minimal (каждая громкость сдвигается не более чем на
  +-20), второе - Medium (до +-50), третье - Random (полностью
  случайные значения), а четвёртое восстанавливает громкости, которые были в выделении
  в начале цикла. Отпускание **OPT** возвращает цикл к Minimal.
  Строки без громкости не затрагиваются.
- **OPT + DOWN** растягивает расставленные ноты нарезанных (sliced) инструментов Sampler в
  выделении в хроматическую последовательность: первая нота каждого инструмента (самая высокая
  в секвенсоре) сохраняет своё значение, а каждая следующая нота этого
  инструмента поднимается на полутон выше предыдущей, превращая стопку
  одинаковых нот в последовательные запуски слайсов. Несколько нарезанных
  инструментов растягиваются независимо, начиная со своих первых нот, ноты
  инструментов без нарезки не затрагиваются, а результат никогда не
  привязывается к гамме проекта. Последняя нота, записанная растяжением, становится
  последней нотой, используемой при вводе, так что продолжение последовательности вручную подхватывает
  следующий слайс. Выделение, содержащее только нарезанные инструменты,
  растягивается при каждом нажатии; если присутствуют и ненарезанные ноты,
  растяжение выполняется при первом нажатии, а со второго нажатия случайное арпеджио берёт на себя
  эти ноты.
- **OPT + DOWN** на выделении без нот нарезанных инструментов - это случайный
  арпеджиатор для нот, уже стоящих там. Аккорд выбирается
  из палитры CRD - 3-нотные аккорды для выделений из 1-2 нот, аккорды из 3 и более нот
  для 3 нот, любой аккорд для 4 и более - с корнем на случайной ноте
  гаммы проекта в регистре выделения (на любой хроматической
  ноте, если гамма выключена или дорожка исключена из него), а его звуки
  квантуются в гамму так же, как это делает воспроизведение для CRD. Каждое
  нажатие заново раскладывает аккорд по расставленным нотам: случайно,
  от низкой к высокой, от высокой к низкой, затем вверх-вниз; 5-е нажатие
  восстанавливает исходные ноты, а следующее выбирает новый аккорд.
  Название аккорда показывается в строке состояния, пока арпеджио активно, ноты
  не добавляются и не удаляются, а отпускание **OPT** сбрасывает весь
  процесс.
- Каждое нажатие заполнения стирает ноты выделения перед записью, а расставленные
  ноты получают последний использованный инструмент; отпускание **OPT** возвращает циклы
  к первому шагу.
- Пока выделение активно и не показывается другое сообщение, строка
  состояния каждые 2 секунды сменяет напоминание об этих комбинациях: `EDIT + DIR =
  batch note edit`, `Double-tap EDIT: resample selection`, `OPT + LEFT =
  pattern fill`, `OPT + RIGHT = random fill`, `OPT + UP =
  mutate/randomize velocity` и `OPT + DOWN = random arp/slice spread`.
  Вход в режим выделения или выход из него перезапускает смену; любое сообщение
  о действии заменяет подсказку, пока не истечёт его время.

### Воспроизведение

- **PLAY** запускает воспроизведение с курсора. Нажмите ещё раз, чтобы остановить.
- Ноты, инструменты и цепочки можно редактировать во время воспроизведения; изменения слышны
  на следующем тике секвенсора.
- **SELECT + PLAY** запускает все дорожки, если используется вне экрана Song.
- **EDIT + PLAY** прослушивает инструмент из Instrument Pool.

## 3. Структура песни и карта экранов

Удерживайте **SELECT + [DIRECTION]**, чтобы переходить между экранами.

Основной ряд навигации:

<pre>
R P   G M
<strong>M S C P I T</strong>
D S     P W
</pre>

Центральный ряд:

- **M**: Mixer (ведёт к Reverb, Delay)
- **S**: Song (ведёт к Project, Settings)
- **C**: Chain
- **P**: Phrase (ведёт к Groove)
- **I**: Instrument (ведёт к Modulation и Instrument Pool)
- **T**: Table (ведёт к редактору AY Wavetable)

Верхний ряд:

- **R**: Reverb
- **P**: Project
- **G**: Groove
- **M**: Modulation

Нижний ряд:

- **D**: Delay
- **S**: Settings
- **P**: Instrument Pool
- **W**: редактор AY Wavetable

Песня в ChooChooTracker строится по такой иерархии:

```text
Song -> Chain -> Phrase row -> Note + Instrument + FX
```

В песне 8 дорожек. Каждая дорожка содержит последовательность цепочек, а каждая цепочка - последовательность фраз. Фразы - это 16-шаговые последовательности нот. Нота состоит из высоты, инструмента, velocity и до 3 FX дорожки. Инструмент - это то, что порождает звук.

### Дополнительные шрифты 16x24 и NostromoAmberDa2

Settings → Load font → fonts/Pixel16x24 содержит TechMonoAudit (преобразованный из Share Tech Mono), Departure Mono, Spleen и Cozette. Каждый предоставляет полный набор печатаемых символов ASCII в ячейках 16×24 для дисплея 640×480. Пиксельные шрифты сохраняют свои исходные пиксели или целочисленное масштабирование с отступами; Cozette остаётся меньше, потому что удвоение её 13-пиксельной высоты знака превысило бы ячейку. Тема NostromoAmberDa2 доступна через Settings → Edit color theme → Load. Она сохраняет янтарный фон и информационный текст Nostromo, с красным основным текстом, более тёмными оранжевыми значениями и бирюзовым курсором. Загрузка этих ресурсов не меняет выбранные вами шрифт и тему. Об авторстве и лицензиях см. прилагаемый README.txt.

### Интервалы на странице Project

Страница Project выводит версию приложения на отдельной строке и отделяет Load, Save, New, Export и Manage от метаданных проекта пустыми строками. Позиции курсора и области касания следуют отображаемым полям; настройки проекта и файловые операции не меняются.

### Телеметрия аудиоиндикации

Аудиоиндикаторы используют принадлежащий интерфейсу снимок итогового микса и вкладов отдельных дорожек. Сэмплы дорожек и стереопики снимаются после уровня дорожки и tilt, перед возвратами общих эффектов и мастер-усилением. Мониторинг не меняет аудиосигнал. Аудио-callback публикует снимки фиксированного размера без блокировок и выделения памяти; отображаемая история охватывает около 21 мс.

### Постоянная осциллограмма

Graphics → Persistent waveform по умолчанию выключено (OFF). Коснитесь EDIT, чтобы переключить, или используйте EDIT + направление; выбор сохраняется как настройка приложения. OFF возвращает страницы на всю высоту и существующие превью осциллограмм инструментов. При включении двухстрочная осциллограмма над страницами редактирования показывает итоговый микс, сведённый в моно. Страницы Instrument и Modulation показывают выход дорожки, использующей выбранный инструмент; если его используют несколько дорожек, приоритет имеет выбранная дорожка Song. Project, Settings, волновые таблицы и всплывающие окна сохраняют содержимое на всю высоту. Списки прокручиваются в оставшихся строках. Нижние части страниц Instrument сохраняют превью ADSR/сэмпла, а поля Modulation уплотняются, чтобы все элементы управления оставались доступными. Её области касания следуют отображаемым полям в обоих режимах осциллограммы.

### Пианино воспроизведения

Нарисованное кодом пиксельное пианино под восемью строками дорожек справа подсвечивает звучащие классы высот, свёрнутые в одну октаву. Оно включает ноты аккордов и учитывает заглушённые и остановленные дорожки. Контур использует цвет значений темы, а все активные клавиши - цвет осциллограммы; неактивные клавиши имеют тёмную заливку и неброские тени. Его сетка использует целочисленное масштабирование и границы фиксированной ширины. Пианино - индикатор воспроизведения, а не средство ввода нот. Всплывающие окна и редактор волновых таблиц сохраняют в этой области собственное содержимое.

### Измерители Mixer

Mixer показывает для каждой дорожки соседние пиковые шкалы **L/R** после её PAN и tilt, перед общими эффектами и мастер-усилением. Шкала охватывает от -48 до 0 dBFS и спадает между обновлениями. Нижняя и средняя полосы используют цвета темы, а верхняя полоса ярко-красная вблизи полной шкалы.

## 4. Song, Chain и Phrase

### Song

Экран Song содержит 8 колонок, по одной на аудиодорожку. Каждая ячейка ссылается на цепочку. Песня может содержать до 256 строк (`00-FF`).

Дорожки идут слева направо, а их цепочки - сверху вниз. Каждая дорожка независима, а цепочки могут содержать от 1 до 16 фраз, поэтому дорожки могут расходиться по времени. Стройте цепочки так, чтобы они оставались вместе, или позвольте им блуждать, если этого требует дорожка.

Обычно одну цепочку резервируют под пустые фразы, как правило `00` или `FE`.

В одном проекте можно держать несколько подпесен, создавая «острова»: секции, разделённые пустыми строками.

#### Live Mode

Дважды коснитесь **OPT**, чтобы войти в Live Mode или выйти из него; `LIVE` заменяет заголовок Song. В Live Mode **PLAY** запускает выбранную цепочку на её дорожке, когда та остановлена. На играющей дорожке он ставит выбранную цепочку в очередь на следующую границу цепочки; нажмите **PLAY** дважды для срочной смены на следующей границе фразы. Выбранная пустая ячейка Song вместо этого ставит в очередь квантованную остановку. `+` отмечает цепочку в очереди, `!` - срочную цепочку, а `-` - остановку в очереди.

Выберите одну строку Song в нескольких колонках, чтобы поставить в очередь или остановить эти дорожки вместе. Выделения из нескольких строк намеренно отклоняются. Очереди Live сбрасываются, пока активен цикл диапазона Song. Live - режим исполнения и в проекте не сохраняется.

#### Управление

- **OPT + [UP/DOWN]**: перейти на 16 позиций вверх или вниз
- Выберите диапазон, затем **SHIFT + EDIT**: поверхностно клонировать цепочки, сохранив их исходные фразы
- Выберите диапазон, затем дважды коснитесь **SHIFT + EDIT**: глубоко клонировать и цепочки, и их фразы
- Выберите диапазон, затем **EDIT + [UP/DOWN]**: сдвинуть выделение вверх или вниз
- Коснитесь **OPT** 3 раза: добавить или убрать подсветку для визуальной организации
- **OPT + SHIFT**: заглушить текущую дорожку или выбранные колонки (сначала отпустите **OPT**, чтобы mute остался включённым)
- **OPT + PLAY**: включить solo текущей дорожки или выбранных колонок (сначала отпустите **OPT**, чтобы solo остался включённым)
- **OPT + [LEFT/RIGHT]**: включить solo всех дорожек слева или справа от текущей
- Выберите диапазон, затем дважды коснитесь **EDIT**: открыть экран BOUNCE TO SAMPLE (см. Bounce ниже)

#### Bounce

Выберите диапазон строк и колонок Song, затем дважды коснитесь **EDIT**, чтобы открыть экран BOUNCE TO SAMPLE. Bounce включает все выбранные дорожки: дорожки, первая цепочка которых начинается позже в выделении, молча ждут и вступают в начале своей первой цепочки, поэтому файл содержит цепочки всех выбранных дорожек.

На экране доступны:

- **File name**: редактируется символьной клавиатурой. При открытии экрана здесь предлагается следующий свободный порядковый номер (`001`, `002`, ...): первый номер, чей файл `.wav` ещё не существует в папке экспорта. Изменяйте его свободно: имя используется как есть. Если файл с таким именем уже существует, добавляется суффикс `_001`, `_002`, ..., чтобы существующие файлы никогда не перезаписывались. Счётчик сбрасывается при загрузке или создании проекта.
- **Sample rate** и **Bit depth**: те же параметры, что и на экране экспорта
- **Include in a sample name**: три флажка, которые добавляют в начало имени файла контекстные теги при нажатии **Start** (по умолчанию все выключены):
  - **[BPM]** - текущий темп проекта, например `[120]`
  - **[Key]** - основная нота и гамма проекта, например `[Cmaj]`, `[F#min Pent]`
  - **[Bars:Beats:16ths]** - отрендеренная длина bounce: одна фраза равна одному такту (16 шестнадцатых), доля - 4 шестнадцатые. Целые фразы показывают только такты, например `[2]`; неполные фразы показывают `[0:2]` (две доли) или `[0:1:3]` (одна доля плюс три шестнадцатые). Для многодорожечных bounce решает самая длинная дорожка. Выделение, заканчивающееся посреди доли, считается на одну шестнадцатую короче: последняя выбранная строка - точка обрезки, поэтому её note-off приходится на конец предыдущей шестнадцатой.
  - Теги применяются в порядке `[BPM][Key][Length]` перед именем файла.
- **Start**: отрендерить выделение в файл WAV в папке экспорта (см. *Export location* на экране Project)
- **Cancel**: вернуться без bounce

Пока идёт рендеринг bounce, **OPT** отменяет его. Когда bounce завершён или отменён, возвращается экран, с которого вы начали.

На компьютере key jazz также даёт здесь прямой ввод шестнадцатеричных индексов, выделение
Shift+стрелками, как в Phrase, Delete/Backspace/Insert и Ctrl+C/X/V - см.
[Key jazz](#key-jazz-только-на-компьютере).

### Chain

Цепочка - упорядоченный список 16-шаговых фраз с необязательным транспонированием. Она может содержать до 16 фраз, и одна и та же фраза может встречаться несколько раз. 2-я колонка задаёт транспонирование в полутонах.

Звёздочка (`*`) появляется рядом с цепочкой, которая повторно используется в проекте. Клонировать цепочки можно с экрана Song.

#### Управление

- **OPT + [LEFT/RIGHT]**: переходить между дорожками
- **OPT + [UP/DOWN]**: переходить между цепочками текущей дорожки
- Выберите диапазон, затем **SHIFT + EDIT**: клонировать фразы
- Выберите диапазон, затем дважды коснитесь **EDIT**: открыть экран BOUNCE TO SAMPLE для выбранных строк цепочки текущей дорожки (см. Bounce в разделе Song)

На компьютере key jazz также даёт здесь прямой ввод шестнадцатеричных индексов - см.
[Key jazz](#key-jazz-только-на-компьютере).

### Phrase

Фраза - это паттерн дорожки в традиционном пошаговом секвенсоре.

Фраза состоит из 16 шагов, по 1 строке на шаг. Каждая строка содержит ноту, инструмент, громкость от `00` до `7F` и колонки FX. Ноты записываются в трекерной нотации, например `C-4` (нота и октава).

Чтобы остановить ноту, вставьте `NOTE OFF`, используйте FX отключения ноты или сыграйте другую ноту без заданного инструмента.

Когда цепочка содержит несколько фраз, экран Phrase работает как непрерывный редактор паттерна. Переход ниже строки `F` или выше строки `0` открывает следующую или предыдущую фразу цепочки.

Звёздочка (`*`) появляется рядом с фразой, которая повторно используется в проекте. Клонировать фразы можно с экрана Chain.

Селектор FX показывает общие команды и те, что поддерживает инструмент в этой строке. Это позволяет избежать длинного общего списка команд, специфичных для движков. ChooChooTracker поддерживает больше FX, чем ChipNomad.

### Управление

- **OPT + EDIT** на пустой ноте: вставить `NOTE OFF`
- **EDIT + [UP/DOWN]** на колонке названия FX: открыть экран выбора FX
- **OPT + [LEFT/RIGHT]**: переходить между дорожками
- **OPT + [UP/DOWN]**: переходить между фразами текущей цепочки
- Выберите диапазон в колонке инструмента, затем **SHIFT + EDIT**: клонировать инструменты
- Выберите диапазон, затем **EDIT + [UP/DOWN]**: циклически сдвинуть строки фразы
- Выберите диапазон, затем дважды коснитесь **EDIT**: открыть экран BOUNCE TO SAMPLE для выбранных строк фразы текущей дорожки (см. Bounce в разделе Song)

### Key jazz (только на компьютере)

Нажмите **Esc** на экране Phrase, чтобы включить или выключить key jazz - режим ввода
нот в стиле QWERTY-пианино (как в [m8c](https://github.com/laamaa/m8c)):

- `Z S X D C V G B H N J M` и `Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P` вводят ноты
  хроматически на два с лишним октавы, используя физическое положение каждой клавиши,
  так что раскладка одинакова на клавиатурах AZERTY, QWERTY и QWERTZ.
- Каждое нажатие записывает ноту в текущую строку и переходит к следующей.
- `[` / `]` сдвигают октаву.
- **Shift + стрелки** выделяют диапазон строк и колонок; простая стрелка
  после этого снимает выделение.
- **Ctrl+C** / **Ctrl+X** копируют или вырезают выбранные колонки, а если ничего не выбрано -
  ноту/инструмент/громкость текущей строки; **Ctrl+V** вставляет в
  позицию курсора.
- **Delete** удаляет строку(и) целиком (все колонки) и сдвигает остаток
  фразы вверх, закрывая пробел; курсор остаётся на той же строке.
- **Backspace** удаляет элемент под курсором только в текущей колонке
  (или в колонках выделения, если оно есть), сдвигает всё, что
  ниже, вверх, закрывая пробел, и возвращает курсор на одну строку назад, как в
  текстовом редакторе.
- **Insert** вставляет пустую строку, сдвигая остаток фразы вниз.
- **Ctrl+S** сохраняет проект. Вне key jazz Ctrl+S ничего не делает.
- Повторное нажатие Esc выключает key jazz.

Пока key jazz включён, он полностью забирает клавиши нот на экране
Phrase, включая сочетания Edit/Opt/Motion, использующие те же клавиши - выключите его
по Esc, чтобы снова ими пользоваться.

Key jazz также работает, включаясь независимо по Esc, на:

- **Song** и **Chain**: вводите шестнадцатеричный индекс цепочки или фразы напрямую
  (`0-9`, `A-F`) вместо увеличения клавишами Up/Down. Первая набранная
  в ячейке цифра заменяет её значение; следующие цифры, набранные без перемещения, сдвигаются
  в неё (набрав «3», затем «F», получаете 3F). На Song **Shift+стрелки** выделяют
  диапазон, **Delete** удаляет строку(и) целиком и сдвигает остальное вверх, **Backspace**
  удаляет текущие/выбранные колонки и сдвигает то, что ниже, вверх,
  **Insert** вставляет пустую строку, а **Ctrl+C**/**Ctrl+X**/**Ctrl+V**
  копируют/вырезают/вставляют выбранные строки (или текущую строку, если ничего не
  выбрано) - это те же сочетания редактирования структуры, что и на экране Phrase.
  Это забирает Shift, поэтому Shift+Right/Up больше не переходят к Chain/Project,
  пока здесь активен key jazz - нажмите Esc, чтобы вернуть эти сочетания.
- **Любой экран с текстовым полем**: печатайте прямо на клавиатуре
  вместо экранной виртуальной клавиатуры. Это охватывает имя файла, название
  и автора на Project, имя инструмента, имя цветовой темы,
  имя таблицы строя, имя файла bounce и диалоги ввода имени (ввод
  имени, создание папки). Backspace работает как в обычном текстовом поле; Shift
  вводит заглавные буквы. Esc переключает его сразу на всех этих экранах,
  а виртуальная клавиатура по-прежнему открывается как обычно, когда key jazz выключен.

## 5. Instruments

У всех инструментов есть несколько общих параметров:

- Тип инструмента
- Имя, до 15 символов
- Скорость таблицы по умолчанию, в тиках на строку таблицы
- Транспонирование включено или выключено

У каждого инструмента есть таблица по умолчанию с тем же номером в диапазоне `00-7F`. Их можно использовать как вспомогательные таблицы, но если держать вспомогательные таблицы в диапазоне `80-FE`, можно избежать конфликтов и путаницы. Таблицы - один из главных инструментов звукового дизайна в ChooChooTracker.

### Управление

- **OPT + [LEFT/RIGHT]**: переходить между инструментами
- **EDIT + PLAY**: прослушать инструмент
- **SHIFT + OPT**: копировать инструмент
- **SHIFT + EDIT**: вставить инструмент

### AY Classic, AY Plus и AY Sample

Это исходные движки AY/YM из ChipNomad. AY Classic предоставляет аппаратные элементы управления тоном, шумом и огибающей. AY Plus добавляет программные осцилляторы и более богатую модуляцию. AY Sample воспроизводит сэмпл через уровни громкости в стиле AY и отличается от движка Sampler.

#### AY Classic

Это устаревший тип инструмента из ChipNomad `v1.0.0`. Более новый инструмент AY Plus предлагает больше возможностей.

У инструментов AY Classic такие параметры:

- Mixer: тон включён или выключен, шум включён или выключен, форма огибающей (`0-F`)
- Volume: программно генерируемая огибающая ADSR
- Автоматический период огибающей: включён или выключен, с соотношением от `1:1` до `F:F`

**AY Quality** в Settings влияет только на рендеринг AY/YM. Он не меняет качество Braids, Plaits или Sampler. **Sample dithering** применяется к квантованию AY Sample.

Подробности о чипе см. в [документации ChipNomad по AY-3-8910](https://chipnomad.org/chips/ay-3-8910/).

#### AY Plus

AY Plus применяет классические концепции синтезатора к звуковому дизайну на AY-3-8910/YM2149F. AY можно считать синтезатором с 5 осцилляторами:

- 3 тоновых осциллятора с прямоугольной волной
- 1 генератор шума
- 1 генератор огибающей амплитуды, который можно использовать как осциллятор

По этой модели у каждого инструмента 3 аппаратных осциллятора: тон, шум и огибающая. AY Plus добавляет 4-й, программный осциллятор. Обновление регистров AY быстрее, чем частота тиков проекта, открывает больше возможностей звукового дизайна. Из-за особенностей работы AY осцилляторы смешиваются кольцевой модуляцией. Пробуйте разные смещения высоты, расстройки и сочетания осцилляторов, чтобы услышать, что получится.

Каждый тональный осциллятор можно настраивать независимо смещениями высоты и точной подстройки.

Типы программных осцилляторов и их параметры:

- Pulse - прямоугольная волна с управляемой шириной импульса
  - FM Depth - глубина простой FM
  - Pulse width - полный диапазон `00-FF`, а число шагов задаётся на экране Project
  - Pulse low - управляет нижним значением в повторяющейся паре, верхнее значение которой всегда `15`
- Sync Tone - эффект жёсткой синхронизации для тонового осциллятора
  - FM Depth - глубина простой FM
- Sync Env - эффект жёсткой синхронизации для осциллятора огибающей
  - FM Depth - глубина простой FM
  - Pulse width - соотношение длительностей 2 форм в паре огибающих
  - Envelope Pair - 2 формы огибающей, между которыми происходит переключение
- Wavetable - 32-шаговые волновые таблицы, редактируемые на экране Wavetable
  - FM Depth - глубина простой FM
  - Wavetable index
- Tone FM - простой FM-подобный эффект для тонового осциллятора
  - FM Depth - глубина FM тона
- Env FM - простой FM-подобный эффект для осциллятора огибающей
  - FM Depth - глубина FM огибающей

Программные осцилляторы Pulse и Wavetable нельзя использовать с осциллятором Envelope. Осциллятор Envelope отключается автоматически.

Простая FM быстро переключается между 2 значениями периода, одним меньшим и одним большим. Это похоже на использование прямоугольной волны в качестве FM-модулятора. Pulse, Sync Tone, Sync Env и Wavetable используют соотношение `1:1` между FM-несущей и модулятором. Tone FM и Env FM могут имитировать другие соотношения через смещения высоты программного осциллятора.

#### AY Sample

Можно загружать моно- или стерео-файлы WAV с разрядностью `8 бит`, `16 бит`, `24 бита` или `32 бита`. Они преобразуются в `8 бит` и обрезаются до `16 КБ`. Этот предел соответствует размеру страницы ОЗУ ZX Spectrum.

AY воспроизводит сэмплы быстрыми записями в регистр громкости. Его выход однополярный, поэтому сэмплы нужно «поднимать до нуля» для более чистого воспроизведения. Это убирает щелчки в конце сэмпла и улучшает тихие хвосты.

У AY ЦАП с разрешением `4 бита` и нелинейной шкалой громкости, поэтому `8-битные` сэмплы при воспроизведении преобразуются в `4-битные`. Параметр Sample dithering в Settings может улучшить воспринимаемую разрядность. Дизеринг неприменим на ретро-платформах вроде ZX Spectrum и Atari ST, поэтому оставляйте его выключенным, когда пишете для реального железа или добиваетесь хрустящего лоу-фай-звука.

Сэмплы ведут себя как ещё один программный осциллятор AY Plus, но их дополнительные параметры удобнее выделить в отдельный тип инструмента.

Параметры сэмпла:

- Sample rate - воспроизведение сэмпла на его родной частоте даёт `C-4`
- Sample start
- Sample length
- Sample loop start
- Sample pitch offset
- Sample fine pitch offset

Секции осцилляторов Tone и Noise совпадают с секциями AY Plus. Из-за особенностей работы AY все осцилляторы смешиваются кольцевой модуляцией.

### Braids

Braids предоставляет 47 моделей синтеза. Его основные элементы управления:

- **Model**: осциллятор или алгоритм синтеза
- **Timbre** и **Color**: макропараметры, зависящие от модели
- **Filter**: дополнительный фильтр LP/BP/HP, крутизна `12` или `24 dB`, частота среза и резонанс
- **ADSR**: attack, decay, sustain и release

Коснитесь **Model**, чтобы выбирать из списков моделей по категориям.

| Категория | Модели |
|---|---|
| Analog | `00 CSAW`, `01 MORPH`, `02 SAW-SQUARE`, `03 SINE-TRI`, `04 BUZZ`, `05 SQUARE-SUB`, `06 SAW-SUB`, `07 SQUARE-SYNC`, `08 SAW-SYNC` |
| Multi Osc | `09 TRIPLE-SAW`, `10 TRIPLE-SQR`, `11 TRIPLE-TRI`, `12 TRIPLE-SINE`, `13 TRIPLE-RING`, `14 SAW-SWARM`, `15 SAW-COMB`, `16 TOY` |
| Filter / Voice | `17 FILTER-LP`, `18 FILTER-PEAK`, `19 FILTER-BP`, `20 FILTER-HP`, `21 VOSIM`, `22 VOWEL`, `23 VOWEL-FOF`, `24 HARMONICS` |
| FM / Chaos | `25 FM`, `26 FEEDBACK-FM`, `27 CHAOTIC-FM` |
| Physical | `28 PLUCKED`, `29 BOWED`, `30 BLOWN`, `31 FLUTED`, `32 STRUCK-BELL`, `33 STRUCK-DRUM` |
| Drums | `34 KICK`, `35 CYMBAL`, `36 SNARE` |
| Wavetables | `37 WAVETABLES`, `38 WAVE-MAP`, `39 WAVE-LINE`, `40 WAVE-PARA` |
| Noise / Granular | `41 FILTER-NOISE`, `42 TWIN-PEAKS`, `43 CLOCK-NOISE`, `44 GRAN-CLOUD`, `45 PARTICLE`, `46 DIGI-MOD` |

#### Параметры

Timbre и Color зависят от выбранной модели. Полный список моделей и подробности см. в оригинальном руководстве Braids от Mutable Instruments, либо просто играйте на слух.

#### VCF и VCA

Braids подаёт сигнал на стандартный многорежимный фильтр и огибающую ADSR ChooChooTracker.

#### Настройки

Глобальные настройки Braids находятся в настройках приложения:

- **BITS**: снижает разрешение выхода
- **DRFT**: добавляет нестабильность высоты осцилляторов
- **SIGN**: воспроизводит алгоритм несовершенства волновой формы оригинального Braids

### aChChid

**aChChid** - монофонический движок acid-баса на основе Open303. `Square` и `Saw` используют родные для TB-303 осциллятор, фильтр, огибающую и поведение акцента. `Braids` заменяет только осциллятор, а затем идёт через тот же тракт фильтра и усилителя 303. Он предоставляет Model, Timbre, Color и Shaper вместо Fine tune. Shaper плавно переходит от мягкой сатурации к волновому сгибанию (wavefolding). aChChid не использует единый постфильтр и ADSR ChooChooTracker.

Cutoff и Decay редактируются логарифмически: **EDIT + LEFT/RIGHT** сдвигает на один
музыкальный шаг управления, а **EDIT + UP/DOWN** - на шестнадцать шагов. Cutoff
охватывает от 200 Hz до 20 kHz; Decay - от 200 ms до 2 s.

`F` в колонке громкости ноты запускает акцент. Обычные ноты используют gate в полшага (3 тика в groove по умолчанию из 6 тиков). `ASL` скользит к этой ноте от предыдущей высоты без перезапуска огибающей 303; он автоматически удерживает предыдущий gate, а `ASL 00` даёт глиссандо в `60 ms`. `ATY` держит свою ноту открытой весь текущий шаг. Ноты без `ASL` всегда перезапускаются. Назначения модуляции включают Decay и Accent, а также Timbre и Color в режиме волны Braids.

### Bogie

**Bogie** - встроенный синтезатор ударных одиночного запуска (one-shot). Ноты трекера задают высоту, а громкость трекера/инструмента задаёт уровень; у каждого запуска своё внутреннее затухание, поэтому страницы ADSR нет. Моделей 12: `Kick`, `Snare`, `Hat`, `Clap`, `Tom`, `Rim`, `FM`, `Noise`, `Cowbell`, `Cymbal`, `Shaker` и `Clave`.

Шесть его макросов: **Decay**, **Tone**, **Sweep**, **Noise**, **FM** и **Drive**. Их подписи подстраиваются там, где это полезно (например, Noise у Kick называется `Click`, а FM у Cowbell - металлическая перекрёстная модуляция). Каждый макрос активен в каждой модели, но его музыкальная роль зависит от модели: Sweep может менять высоту, интервал между всплесками или металлический разброс; FM может добавлять перекрёстную модуляцию, металлический слой или кольцеподобный обертон. Нижняя половина каждого диапазона предназначена для привычных звуков ударных; верхняя половина намеренно открывает более широкие тембровые метаморфозы и более синтетические результаты.

Любую модель можно пропустить через общий многорежимный фильтр LP/BP/HP с характером Clean, Classic, Aggro или Acid, крутизной `12`/`24 dB`, частотой среза и резонансом. Bogie поддерживает все свои активные макросы плюс Volume, Pitch, Cutoff и Resonance как назначения модуляции и записи движения. Используйте короткий Decay с Cowbell для резких phonk-атак; увеличьте FM для более жёсткого, металлического колокольчика.

На экране Modulation нажмите **EDIT** на источнике, чтобы выбрать семейство (Envelopes, LFO или Sticks), а затем сам источник. **Left** и **Right** по-прежнему перебирают источники напрямую.

### Sintered

**Sintered** - встроенный цифровой перкуссионный синтезатор одиночного запуска. Ноты задают его основную высоту; шесть его моделей: `Knot`, `Shard`, `Burst`, `Comb`, `Logic` и `Melt`. У каждой модели есть **Decay**, **Mod** и **Motion**, а также три параметра, специфичных для модели: Knot использует Ratio/Spread/Fold, Shard - Ratio/Feedback/Bite, Burst - Noise/Color/Feedback, Comb - Time/Damping/Regen, Logic - Rate/Pattern/Crush, Melt - Ratio/Chaos/Drive. **Mod** - всегда глубина внутренней связи.

Motion - внутренняя макро-огибающая, а не глиссандо высоты: значения ниже `80` дают форму AD, `80` отключает её, а значения выше `80` дают форму только с затуханием. Чем дальше от центра, тем быстрее огибающая. Её назначения фиксированы для каждой модели, поэтому Sintered остаётся предсказуемым в паттернах трекера: Knot анимирует Mod/Fold; Shard - Feedback/Bite; Burst - Noise/Color/Feedback; Comb - Damping/Regen; Logic - Rate/Crush; Melt - Chaos/Drive. Все модели сбрасывают своё состояние при запуске ноты и ограничивают внутреннюю обратную связь для воспроизводимых ударов.

### MME

**MME** (Multi Modulation Engine) - синтезатор с двумя осцилляторами, посвящённый взаимодействию осцилляторов. Его модели: `Ring`, `Fold`, `Cross`, `VPM`, `Sync`, `Logic` и `Vocode`. Оба осциллятора внутренние и следуют нотам трекера; `Interval` задаёт их соотношение.

Шесть макросов: **Waves**, **Interval**, **Amount**, **Flow**, **Feedback** и **Shaper**. Waves выбирает музыкальные пары волновых форм A/B. Amount управляет основным взаимодействием модели, Flow меняет его направление или вариант алгоритма, а Feedback ограничен, но к концу диапазона намеренно становится диким. Shaper - общая финальная ступень, переходящая от чистого звука через сатурацию к волновому сгибанию.

MME использует общий многорежимный фильтр LP/BP/HP и ADSR. Все шесть макросов, Cutoff и Resonance доступны для модуляции и записи движения. Удерживайте **EDIT** на Model, чтобы открыть окно моделей.

### MIDI Out

**MIDI Out** (только на компьютере) управляет внешним MIDI-устройством вместо синтеза звука: запуск ноты отправляет настоящее MIDI Note On на **Channel** инструмента (`1-16`), а по окончании ноты - соответствующее Note Off. Громкость становится velocity, а у каждого голоса аккордовой дорожки свои Note On/Off. Сам ChooChooTracker звука не издаёт - сначала выберите устройство вывода в [Settings](#12-settings). Полную картину, включая прослушивание звука с MIDI-клавиатуры, см. в [MIDI](#14-midi).

**Program** и **Bank high/low** (CC0/CC32) необязательны - при выключении показываются как `--`, `Clear` выключает поле, запоминая его значение. Если заданы, они отправляются один раз, прямо перед следующей нотой, всякий раз, когда отличаются от того, что последним сообщили этому каналу (а не перед каждой нотой, что перезапускало бы собственные огибающие или патч принимающего устройства).

**MC1 number**-**MC4 number** выбирают, на какой номер CC (`00-7F`) отправляет каждый из четырёх FX строки MC1-MC4 - см. [MIDI Out FX](#fx-midi-out). Тоже `--`/необязательно; незаданный слот делает свой FX бездействующим.

### Субтрактивные движки

Движки этой категории используют общую архитектуру VCO - VCF - VCA.

Доступно несколько типов VCO:

- **Braids**
- **Plaits**
- **Plaits-Alt**
- **Sampler**
- **2xSCWF**
- **BYOWTBL**

Каждый инструмент подаёт свой VCO на многорежимный фильтр.

У фильтра переключаемая крутизна `12 dB` или `24 dB`, и он может работать как фильтр нижних частот (LP), полосовой (BP) или фильтр верхних частот (HP).

Доступно несколько характеров фильтра:

- **Clean**: стерильный и цифровой
- **Classic**: вдохновлён классическими американскими аналоговыми синтезаторами
- **Aggro**: вдохновлён ревущими японскими аналоговыми синтезаторами
- **Acid**: вдохновлён психоделиками

Classic, Aggro и Acid в этой альфа-версии могут сильно резонировать. Начинайте с малых значений и прибавляйте осторожно.

Фильтр подаёт сигнал на VCA, управляемый огибающей ADSR. Форма огибающей может плавно меняться между экспоненциальной, линейной и логарифмической кривыми.

#### Plaits и Plaits-Alt

**Plaits** предоставляет 24 движка, сгруппированных в окне выбора следующим образом:

| Категория | Движки |
|---|---|
| Analog / Waves | `00 VA VCF`, `01 PHASE DIST`, `05 WAVE TERRAIN`, `06 STRING MACH`, `08 VIRTUAL ANALOG`, `09 WAVESHAPING`, `11 FORMANT`, `12 HARMONIC`, `13 WAVETABLE`, `14 CHORD` |
| FM | `02 6-OP FM 1`, `03 6-OP FM 2`, `04 6-OP FM 3`, `10 2-OP FM` |
| Digital | `07 CHIPTUNE`, `15 SPEECH` |
| Texture / Noise | `16 SWARM`, `17 NOISE`, `18 PARTICLE` |
| Physical | `19 STRING`, `20 MODAL` |
| Drums | `21 BASS DRUM`, `22 SNARE DRUM`, `23 HI-HAT` |

**Plaits-Alt** - коллекция альтернативных моделей для оригинального модуля Plaits. Большинство из них более странные или экспериментальные, чем средний VCO.

| Категория | Движки |
|---|---|
| Granular / Micro | `GLISSON`, `PULSAR`, `GENDY`, `SCANNED`, `LOOPBACK` |
| Phase / Harmonic | `PHASE WEAVE`, `SIDEBAND BANK`, `UNDERTOW`, `ATTRACTOR`, `LOCKSTEP` |
| Acoustic / Physical | `REED PIPE`, `BRASS`, `SHAKERS`, `CLAPS`, `FRESHETS FORMANT` |
| Polyphony / Harmony | `DIATONIC CHORD`, `SCALE STACK`, `WT DIATONIC CHORD`, `WT SCALE STACK`, `HELIX` |
| Digital / Weird | `BYTEBEAT`, `RULEFIELD`, `SPECTRAL SPIRAL`, `PHASE FLOCK` |

Параметры следуют замыслу Mutable:

- **Harmonic** управляет гармоническими соотношениями, балансом или выбором модели внутри движка.
- **Timbre** обычно переходит от тёмных/разреженных к ярким/плотным спектрам.
- **Morph** исследует ещё одно измерение тембра.
- **Main/Aux** смешивает основной выход с альтернативным выходом движка.

Их точный смысл зависит от движка. Например, аккордовые движки используют их для типа аккорда, обращения и формы волны. Физические модели используют их для материала, возбуждения и затухания, а движки ударных - для тона, характера и затухания. Подробности см. в руководстве пользователя Plaits.

Для `CHORD`, `DIATONIC CHORD` и `WT DIATONIC CHORD` Harmonic показывает название выбранного аккорда (`MIN`, `MAJ`, `MIN7`, `MAJ7` и так далее), а не его необработанное значение. `WAVE PARA` в Braids аналогично называет свои вариации расположения голосов Color.

Коснитесь **Engine**, чтобы выбирать из списков движков по категориям.

**Env Mode** имеет 2 маршрутизации:

- `TRIG` воспроизводит модуль с подключённым TRIG и неподключённым LEVEL
- `VCA` держит LEVEL открытым и применяет ADSR трекера после голоса

#### Sampler

Этот чистый движок сэмплов воспроизводит моно- или стерео-PCM-сэмплы, загруженные в ОЗУ.

- Коснитесь **Sample**, чтобы загрузить несжатый PCM WAV с разрядностью `8 бит`, `16 бит` или `24 бита`. Нажмите **PLAY** в браузере, чтобы прослушать выделенный файл.
- Когда сэмпл загружен, рядом с его именем появляется **EDIT**. Коснитесь его, чтобы открыть экран Sample Edit. **OPT** или **SELECT + [LEFT]** возвращает к инструменту.
- Экран Sample Edit показывает имя файла (с маркером `*`, когда сэмпл в ОЗУ отличается от файла на диске), информацию о формате (частота дискретизации, каналы), высокую осциллограмму и поля **Region**, **Select**, **Slice**, **Process** и **File**.
- Правки живут только в ОЗУ, пока их не запишет один из сценариев сохранения: проект хранит путь к файлу сэмпла и при следующей загрузке проекта перечитывает WAV с диска, поэтому выход из трекера без **Save**/**Save As** отбрасывает операции обработки (маркер `*` - это предупреждение). Загрузка другого сэмпла в инструмент также отбрасывает несохранённые правки и возвращает Region на весь сэмпл (Start `00`, End `FF`).
- **Region** задаёт маркеры воспроизведения Start/End, также доступные на экране инструмента Sampler. Они задают нормализованные границы воспроизведения (`00-FF`); если Start стоит после End, сэмпл играет в обратном направлении. **EDIT + [LEFT/RIGHT]** точно подстраивает маркер с шагом в единицу (`01`) и масштабирует осциллограмму вокруг него, пока удерживается **EDIT**; **EDIT + [UP/DOWN]** подстраивает грубо (шаг 16) и возвращает вид на весь сэмпл. **EDIT + OPT** возвращает маркер к значению по умолчанию (Start `00`, End `FF`).
- Вид осциллограммы масштабируется до фиксированного окна в одну секунду звука вокруг редактируемого маркера и прокручивается, чтобы держать его в поле зрения; сэмплы, помещающиеся в окно, остаются в полном виде 1:1. Масштаб временный: он действует, пока удерживается **EDIT**, а отпускание **EDIT** возвращает полный вид 1:1, так же как и грубые шаги. Вход на экран всегда возвращает вид на весь сэмпл.
- **Select** задаёт выделение для обработки в абсолютных кадрах, независимое от маркеров воспроизведения Start/End. **EDIT + [LEFT/RIGHT]** сдвигает маркер на двадцать кадров и масштабирует вид на нём, пока удерживается **EDIT**; **EDIT + [UP/DOWN]** переходит на `frameCount/64` (минимум 16) и возвращает вид на весь сэмпл. **EDIT (касание)** на маркере копирует в него текущую позицию маркера Start или End. **EDIT + OPT** на любом из маркеров очищает всё выделение. Когда выделение пусто, оба маркера показывают `-`; когда маркеры инвертированы, они автоматически меняются местами. Выделение - состояние редактора только на время сессии: оно не сохраняется с проектом, а при входе на экран инициализируется протяжённостью Region воспроизведения (весь сэмпл при маркерах по умолчанию).
- **Slice** - одна строка с четырьмя ячейками значений - **Mode**, **Count**,
  **Slice** и **Frame** - и сохраняется вместе с инструментом. Off воспроизводит
  окно Start/End. Ноты фраз выбирают слайсы хроматически начиная с **C-0**, а
  ноты за последним слайсом возвращаются к началу (нота N играет слайс
  `N % count`, так что последовательность за последним слайсом возвращается к первому).
  Нарезанные ноты не транспонируют высоту и не используют квантование Scale, но **CRD**
  сохраняет выбранный слайс и транспонирует его голоса как аккорд. Начала слайсов
  отмечены на осциллограмме короткими линиями шириной в два пикселя (тёмно-оранжевыми; линия
  текущего слайса ярче), а слайс под курсором получает
  чёрную полосу фона на осциллограмме (тон выделения поверх полосы не рисуется,
  поэтому она остаётся полностью чёрной и чётко отличается от остальной части
  превью).
  - **Mode** перебирает `OFF` / `EQUAL` / `AUTO` / `LAZY` (EDIT + влево/вправо или
    касание; EDIT + OPT выключает нарезку). Смена режима инициализирует точки
    слайсов: **EQUAL** делит окно Start/End поровну на **Count**
    частей; **AUTO** запускает обнаружение транзиентов в окне и ставит
    слайс на каждое найденное вступление (до **Count**); **LAZY** начинается с одного
    слайса, покрывающего всё окно. Переход в LAZY откладывает текущие настройки
    EQUAL/AUTO (число и границы), а возврат к EQUAL или
    AUTO восстанавливает их без изменений - подтверждения не запрашивается и ничего не
    теряется. Slice и Stretch взаимоисключающи: включение одного отключает
    другой, а ячейки Slice затемнены, пока длительностью управляет Stretch.
  - **Count** показывает общее число слайсов (`01`..`64`). **EDIT +
    [LEFT/RIGHT]** меняет его на единицу (минимум 1, максимум 64), **EDIT +
    [UP/DOWN]** перебирает числа, равные степеням двойки: `2 / 4 / 8 / 16 / 32 /
    64`, с зацикливанием. Каждое изменение пересчитывает деление: **EQUAL**
    заново делит окно поровну, **AUTO** заново запускает обнаружение с новой
    целью (чувствительность обнаружения выводится из числа - больше слайсов
    означает более чувствительный порог). В поле показывается `-`, когда режим
    OFF. В **LAZY** оно остаётся ярким (оно считает слайсы, расставленные вручную), но
    только отображает: курсор его пропускает - движение вправо от **Mode** или
    влево от **Slice** попадает на **Slice**, переход вниз с маркера **END**
    строки **Select** тоже попадает туда, а касание поля ничего не делает
    (у слайсов, расставленных вручную, нет деления для пересчёта). **EDIT + OPT** и
    простое касание **EDIT** здесь ничего не делают: выключение нарезки находится
    на **Mode**, удаление слайса - на **Slice**.
  - **Slice** - это браузер: он показывает текущий слайс, нумерация с 1
    (`01`..count). **EDIT + [LEFT/RIGHT]** переходит между слайсами по одному,
    **EDIT + [UP/DOWN]** перескакивает на четыре слайса (в обоих случаях с ограничением, без
    зацикливания); просматриваемый слайс отмечается на осциллограмме более ярким
    маркером и чёрной полосой, а масштабированный вид центрируется на начале слайса.
    **EDIT + OPT** удаляет текущий слайс (он сливается с
    предыдущим; первый слайс удалить нельзя, а удаление
    последнего оставшегося слайса выключает нарезку - границы переживают переход
    через OFF и возвращаются, когда режим выбирается снова). **EDIT (касание)**
    прослушивает выбранный слайс одиночным воспроизведением (работает в
    каждом режиме слайсов; прослушивание останавливается при отпускании клавиши или при выходе
    с экрана). В поле показывается `-`, когда режим OFF.
  - **Frame** показывает начальный кадр текущего слайса в шестнадцатеричном виде. **EDIT +
    [LEFT/RIGHT]** сдвигает его на десять кадров (масштабируя вид на маркере, пока
    удерживается **EDIT**), **EDIT + [UP/DOWN]** сдвигает на сто и
    возвращает полный вид. Маркер остаётся внутри собственного слайса: он
    не может пересечь начало предыдущего или следующего слайса. **EDIT + OPT** удаляет
    слайс.
  - **B** возвращает на экран инструмента со строки Slice, как и везде
    на этом экране; **SHIFT + LEFT** выходит откуда угодно.
  - **Рабочий процесс LAZY**: при выбранном LAZY коснитесь **PLAY**, чтобы запустить
    одиночное воспроизведение всего сэмпла - он играет один раз с начала и останавливается
    сам, на исходной высоте и скорости сэмпла (зелёный двухпиксельный
    маркер следует за позицией на осциллограмме); повторное касание **PLAY**
    останавливает его раньше. Пока он играет,
    каждый щелчок **EDIT** ставит слайс в позиции воспроизведения, где бы
    ни был курсор (слайсы ближе 50 ms к существующему отклоняются
    с сообщением `Too close to slice`). Повторное воспроизведение сэмпла сохраняет
    существующую нарезку и добавляет новые слайсы в каждой отмеченной позиции, по
    порядку - поле **Count** обновляется с каждым поставленным слайсом, а
    браузер **Slice** следует за новым. К слайсам, расставленным вручную, применяются те же правила
    просмотра и редактирования, что и в других режимах: **EDIT +
    направление** на **Slice** просматривает их, **Frame** подстраивает выбранное
    начало, **EDIT + OPT** удаляет текущий слайс. Ячейка Frame затемнена,
    пока вставка во время воспроизведения подготовлена. **SHIFT + PLAY** в LAZY не
    перехватывается: он запускает воспроизведение фразы, как на любом другом экране. Слайсы
    LAZY играют в секвенсоре точно так же, как EQUAL и AUTO: ноты фраз
    хроматически сопоставляются начиная с **C-0** слайсам, расставленным вручную,
    с зацикливанием после последнего.
  - **Подсказки о комбинациях**: пока курсор стоит на ячейке строки Slice и не показывается другое
    сообщение, строка состояния показывает подсказку для этой ячейки и держит её,
    пока курсор остаётся на ней. На **Mode** подсказка привязана к
    активному режиму и показывает только описание (название режима уже есть в
    ячейке): `Divides sample in equal parts`, `Divides sample based on
    transients`, `Press Play and add slices with EDIT` - смена режима
    сразу заменяет текст, а OFF очищает строку. На **Count** она
    показывает `Adjust the number of slices`, на **Slice**
    `Browse slices`, на **Frame** `Adjust slice start`. Любое сообщение о действии
    заменяет подсказку, пока не истечёт его время.
- **Process** выбирает деструктивную операцию редактирования: **Crop**, **Normalize**, **Delete**, **Silence**, **Fade In**, **Fade Out** или **Reverse** (EDIT + влево/вправо перебирает, касание перебирает вперёд, EDIT + OPT не выбирает ничего). **GO** (в той же строке) выполняет выбранную операцию над текущим выделением, а при пустом выделении - над всем сэмплом. **Crop** оставляет только выделение; **Normalize** масштабирует выделение так, чтобы его пик достиг полной шкалы (оба канала используют одно усиление, чтобы сохранить стереокартину); **Delete** удаляет выделение и склеивает концы (удаление всего сэмпла отклоняется); **Silence** обнуляет его; **Fade In**/**Fade Out** линейно поднимают/опускают выделение от тишины/до тишины; **Reverse** воспроизводит выделение в обратном направлении (кадры меняются местами на месте, оба канала кадра двигаются вместе, длина и маркеры не меняются). Crop и Delete требуют выделения - при пустом выделении они показывают `Select region first`. Каждая операция ненадолго приостанавливает звук, хранит один уровень отмены и помечает сэмпл как изменённый в ОЗУ: файл на диске не затрагивается до сценариев Save (см. ниже), а выход с экрана отбрасывает слот отмены.
- **UNDO** (рядом с GO) возвращает сэмпл к состоянию перед последней операцией. Он затемнён, пока не выполнена ни одна операция, при повторных нажатиях переключается между состояниями до и после операции и очищается при повторном входе на экран.
- **File** содержит сценарии сохранения. Инструмент хранит полный путь к WAV, из которого он был загружен; эти сценарии записывают этот файл или направляют инструмент на новый. Они никогда не затрагивают имя инструмента.
  - Поле File переключается между **Save** и **Save As** (EDIT + влево/вправо или касание); **GO** (в той же строке) выполняет показанное действие.
  - **Save** перезаписывает WAV, из которого был загружен сэмпл. Для сэмпла
    без слайсов сначала спрашивается `Overwrite <name>?`. Нарезанный сэмпл сначала
    открывает диалог **SAVE SLICES**, спрашивающий, куда относятся точки слайсов:
    **SAVE TO SAMPLE** записывает их в WAV как блоки cue (переносимо -
    DAW показывают их как маркеры) и также сохраняет в проекте,
    **SAVE TO PROJECT** записывает обычный WAV и сохраняет точки
    только в проекте, **CANCEL** прерывает. Флажок `Don't ask again in this project`
    сохраняет выбранное назначение вместе с проектом и в дальнейшем пропускает
    диалог (выбор сохраняется как `- Sample save choice:` в
    .cct и может быть изменён только правкой файла проекта). Диалог
    пропускается для сэмплов без слайсов. **Save** затемнён (и
    пропускается при навигации), пока не загружен сэмпл с путём к файлу. Неудачная
    запись сохраняет маркер изменения и показывает ошибку.
  - **Save As** записывает текущий сэмпл в новый файл: введите имя файла (по умолчанию подставляется текущее имя без расширения), затем выберите папку в браузере. Сэмпл записывается как `<folder>/<name>.wav`, инструмент указывает на новый файл, а папка запоминается как папка сэмплов по умолчанию. Он затемнён (и пропускается при навигации), пока не загружены данные сэмпла, так что только что загруженному сэмплу можно задать путь к файлу. Пути длиннее 255 символов отклоняются.
  - Маркер `*` перед именем файла означает, что сэмпл в ОЗУ отличается от файла на диске (его устанавливает любая операция обработки, а Save и Save As сбрасывают). Маркер действует только в рамках сессии: он не сохраняется в проекте и сбрасывается при повторном входе на экран. Если несколько инструментов ссылаются на один и тот же файл WAV, сохранение одного перезаписывает файл для всех.
- На экране инструмента Sample используйте **EDIT + [LEFT/RIGHT]**, чтобы загрузить предыдущий или следующий WAV из той же папки.
- **Pitch** транспонирует в полутонах (от `-48` до `+48`).
- **Loop** выбирает Off, Loop или Ping-Pong.
- **Speed** управляет гранулярным растяжением времени от `0%` до `500%` (`100%` - норма).

Неподдерживаемые форматы WAV показывают ошибку. Перед импортом преобразуйте необычные файлы в WAV `PCM8`, `PCM16` или `PCM24`.

#### 2xSCWF

2xSCWF - двойной осциллятор однопериодной волновой формы. Загрузите в каждый осциллятор по 1 моно-WAV, содержащему ровно 1 период. Оба осциллятора читают вперёд и зацикливаются в конце своего цикла.

Mix плавно переходит между A и B.

Detune - тонкая и экспоненциальная от унисона до `+200 ct`, затем идёт полутоновыми шагами от `+3 st` до `+24 st`.

2xSCWF рассматривает каждый файл как таблицу из 1 цикла и читает её ровно один раз за цикл осциллятора. Это позволяет смешивать и расстраивать 2 однопериодные волны.

Заводская папка `waveforms/AKWF/` содержит волновые формы из библиотеки Adventure Kid. Гораздо больше их доступно в сети, если хотите расширить коллекцию.

#### BYOWTBL

BYOWTBL - двойной осциллятор с волновыми таблицами, совместимый с таблицами Serum. Каждый осциллятор загружает моно-WAV, содержащий последовательные однопериодные кадры. `Pos A` и `Pos B` независимо сканируют свои таблицы от `00` до `FF`. Движок линейно интерполирует внутри каждого кадра и между соседними кадрами. `Mix` плавно переходит между осцилляторами, а `Detune` смещает осциллятор B.

## 6. Модуляция и запись движения

У каждого инструмента может быть до 4 слотов модуляции. Аудиоинструменты могут нацеливаться на **Instrument Pan** или **Track Pan**; оба используют `00` для левого края, `80` для центра и `FF` для правого края.

Доступные типы модуляции:

- ADSR - классическая огибающая attack-decay-sustain-release
- AHD - огибающая attack-hold-decay
- LFO - низкочастотный осциллятор с несколькими формами
- SLFO - LFO с множителем периода для медленных циклов
- FLFO - LFO звуковой частоты, достигающий диапазона кГц; FLFO может сильно нагружать CPU
- SLIN - линейное управление джойстиком
- SRAT - управление джойстиком по скорости изменения

Список назначений модуляции зависит от типа инструмента.

Для назначения `Cutoff` Amount экспоненциален с квадратичным откликом: 25% достигает 4,5 полутонов, 50% - 18 полутонов, 75% - 40,5 полутонов, а 100% - шести октав. Это сохраняет точное управление при малых значениях, но всё же допускает глубокие свипы.

Когда огибающая ADSR или AHD нацелена на Volume, она становится огибающей громкости инструмента. LFO, нацеленный на Volume, вместо этого смещает текущую выходную громкость.

Величина модуляции может быть положительной или отрицательной. Её диапазон зависит от назначения. Если полный диапазон назначения равен `127` или меньше, как у большинства параметров, величина задаёт абсолютный диапазон. Более широкие назначения, например высота, используют масштабированную величину.

Все параметры длительности, включая attack, hold, decay и период, измеряются в тиках.

Формы LFO:

- Tri - биполярная треугольная волна
- Sin - биполярная синусоида
- UniTri - однополярная треугольная волна
- UniSin - однополярная синусоида
- RampDn - линейный спад (пилообразная волна)
- RampUp - линейный подъём (пилообразная волна)
- ExpDn - экспоненциальный спад (экспоненциальная пилообразная волна)
- ExpUp - экспоненциальный подъём (экспоненциальная пилообразная волна)
- Square - прямоугольная волна
- Random - случайная волна «выборка-хранение» (sample-and-hold)
- Wavetable - читает одну из 32-шаговых волновых таблиц AY проекта. Значения от `00` до `0F` отображаются от `-100%` до `+100%` без интерполяции.

Типы запуска LFO:

- Free - перезапускает LFO только при смене инструмента
- Retrig - перезапускает LFO на каждой ноте
- Phrase - перезапускает LFO и SLFO, когда воспроизведение входит в новую фразу
- Chain - перезапускает LFO и SLFO, когда воспроизведение входит в новую цепочку
- Hold - останавливается после 1 цикла и удерживает последнее значение
- Once - останавливается после 1 цикла и возвращается к нулю

### Запись движения (Motion recording)

- **STICK LIVE** (`L1` по умолчанию) применяет модуляцию стиками, не меняя фразу. В **Settings > Stick live mode** `HOLD` (по умолчанию) включает её, пока кнопка удерживается; `TOGGLE` включает одним нажатием и выключает следующим; `FREE` оставляет её включённой постоянно. Отпускание кнопки в `TOGGLE` оставляет её включённой.
- Во время воспроизведения удерживайте **MOTION RECORD** (`L2`), чтобы применять модуляцию стиками и записывать изменённые назначения как абсолютные значения FX.
- Удерживайте **MOTION ERASE** (`R2`), чтобы удалить из текущей строки соответствующие FX назначений.

`~` в правом нижнем углу означает активный Stick live. Record (`*`, или `!` при переполнении) и Erase (`x`) имеют приоритет индикатора и остаются кратковременными в обоих режимах. Оба включают живую обработку стиков, пока удерживаются; их отпускание оставляет нетронутым отдельно включённый живой переключатель.

Режим сохраняется вместе с настройками приложения, но живой переключатель при запуске всегда выключен. Смена режима сбрасывает переключатель: `HOLD` следует за любой удерживаемой в данный момент кнопкой Stick live, `TOGGLE` ждёт нового нажатия, а `FREE` активен сразу.

Запись движения пишет FX дорожки в воспроизводимую в данный момент фразу. Сначала она обновляет соответствующие FX, затем использует пустые слоты справа налево. Она никогда не перезаписывает другой FX. Если все 3 слота заняты, это движение на шаге не записывается. `!` в правом нижнем углу означает, что изменилось больше назначений, чем могли вместить 3 колонки FX.

Запись движения поддерживает назначения Braids, Plaits, Sampler, 2xSCWF, BYOWTBL и Bogie, включая активные макросы Bogie и элементы управления фильтром, где это применимо.

## 7. Tables

Таблицы - основной инструмент звукового дизайна в трекерах. В терминах Vortex Tracker они объединяют инструменты и орнаменты, но умеют гораздо больше. Если вы знакомы с LSDj или NerdSEQ, идея должна быть уже понятной.

Колонка Pitch принимает относительные (`~`) или абсолютные (`=`) значения высоты в полутонах. Колонка Volume - `00`-`0F`, применяется ко всем движкам поверх их огибающей и может использоваться как gate: чередуйте `0F` и `00`, затем зациклите с помощью `HOP 00`. 4 дорожки FX в основном совпадают с дорожками фразы, хотя несколько FX в таблицах ведут себя иначе.

FX `TIC` в последней строке таблицы задаёт скорость этой колонки и переопределяет скорость таблицы по умолчанию для инструмента. Каждая колонка FX может работать с собственной скоростью тиков. Колонки Pitch и Volume следуют скорости 1-й колонки FX.

Таблица из 16 строк может показаться короткой рядом с длинным инструментом Vortex Tracker, но FX `HOP` позволяет создавать условные циклы вроде «повторить эти строки 5 раз», а также вложенные циклы. С циклами и независимыми скоростями колонок FX эти 16 строк уводят на удивление далеко.

### Режим Retrigger

Поле `Retrig` в верхней части экрана Table выбирает, когда уже активная таблица перезапускается. `Inst` - режим по умолчанию и режим совместимости: строка фразы с инструментом выбирает таблицу по умолчанию этого инструмента и запускает её со строки `00`. `Phrase` перезапускает активную таблицу, когда воспроизведение входит в фразу, `Chain` - когда входит в цепочку, а `Free` оставляет её работать, пока дорожка не остановится или явная команда не заменит её.

Структурный режим никогда не заглядывает назад во времени. Если на дорожке нет активной таблицы инструмента, первая строка фразы, вводящая инструмент, активирует его таблицу ровно на этой строке, даже если это строка `4`, `8` или `F` фразы. Последующие номера инструментов не заменяют активную таблицу `Phrase`, `Chain` или `Free`. Это делает таблицы полезными как LFO-подобную автоматизацию без скрытой имитации более ранних шагов фразы.

`TBL`, `TBX` и `RET` всегда являются явными действиями: они выбирают или перезапускают немедленно, независимо от режима. На границе Phrase или Chain перезапуск происходит до чтения новой строки фразы, поэтому `TBL` или `TBX` в этой строке имеет последнее слово. FX строки `00` таблицы поэтому снова выполняются как обычно; накопительные FX сохраняют своё обычное накопление.

Таблицы `00-7F` зарезервированы под таблицы инструментов по умолчанию. Таблицы `80-FE` предназначены для вспомогательных таблиц, запускаемых эффектом `TBX`. Нижний диапазон также работает для вспомогательных таблиц, но такое использование может вызвать неожиданные конфликты и путаницу.

### Копирование FX между Phrase и Table

Выберите только колонки названия/значения FX, затем скопируйте или вырежьте их из Phrase и вставьте в любую дорожку FX в Table, либо наоборот. Копия сохраняет точно выбранные ячейки, поэтому выделение только команд или только значений остаётся частичным. Вставка начинается с текущей ячейки FX и обрезается на строке `F` и на последней дорожке FX назначения. Ноты, номера инструментов, высота и громкость никогда не переходят между этими двумя экранами.

### Управление

- **EDIT + [UP/DOWN]** на колонке названия FX: открыть экран выбора FX
- **OPT + [DIRECTION]**: переходить между таблицами

## 8. Другие экраны

### Instrument Pool

Instrument Pool показывает все инструменты проекта и позволяет менять их порядок. Во время воспроизведения он также показывает, какие инструменты сейчас активны.

#### Управление

- **EDIT**: редактировать инструмент и перейти на экран Instrument
- **SHIFT + OPT**: копировать инструмент
- **SHIFT + EDIT**: вставить инструмент
- **EDIT + [UP/DOWN]**: менять порядок инструментов
- **EDIT + PLAY**: прослушать инструмент

### AY Wavetable

Wavetable - тип программного осциллятора AY Plus. Проект может содержать до 256 волновых таблиц по 32 шага. Все инструменты с волновыми таблицами используют один и тот же набор волн. На этом экране вы их редактируете.

Уровни громкости AY нелинейны, поэтому волна вида Standard рисуется так, чтобы соответствовать реальным выходным уровням. Дважды коснитесь **OPT**, чтобы переключаться между видом Standard и сохраняемым **видом LFO**, тем же сочетанием, что и для Song/Live Mode: вид LFO линейно рисует необработанные шаги `0`-`15`, а центральная линия между `7` и `8` служит нулём модуляции.

На экране 2 логические строки. Верхняя содержит кнопки **Load** и **Save**, а 2-я - редактор волновой таблицы.

#### Управление

- **OPT + [LEFT/RIGHT]**: перемещаться по списку волновых таблиц
- **OPT + [UP/DOWN]**: перемещаться по списку по 16 волн
- **SHIFT + OPT**: копировать волновую таблицу
- **SHIFT + EDIT**: вставить волновую таблицу
- **OPT + PLAY**: переключаться между видами Standard и LFO

## 9. FX дорожки (Tracker FX)

FX дорожки принудительно задают значения секвенсора или звукового движка на отдельных шагах. Другие грувбоксы часто называют это «parameter locks». В каждой строке Phrase есть 3 слота FX.

У каждого FX есть команда из 3 букв и шестнадцатеричное значение. Встроенная справочная панель приложения даёт краткое описание выбранной команды.

### Автоматизация гаммы (Scale)

`SCL XY` меняет глобальную гамму и основную ноту воспроизведения, не меняя ноты, сохранённые во фразах. `X` выбирает гамму (`0` Chromatic, `1` Major, `2` Minor, и так до `C` Custom); `Y` выбирает основную ноту (`0` C до `B` B). Команда применяется только к FX фраз, но не таблиц. Если несколько дорожек выдают `SCL` на одном тике, побеждает дорожка с наименьшим номером.

`SCL` относится к режиму Quantizer. При активном **Note Lock** команда не предлагается в списке FX, а любой `SCL`, уже записанный во фразы, игнорируется, пока этот режим включён.

### Аккорды (Chords)

`CRD XY` превращает ноту в своей строке Phrase в аккорд. `Y` выбирает: `0` Major, `1` Minor, `2` Dim, `3` Aug, `4` Sus2, `5` Sus4, `6` Power, `7` Maj7, `8` Min7, `9` Dom7, `A` Min7b5, `B` Dim7, `C` Add9, `D` MinAdd9, `E` Maj9 или `F` Min9. `X` выбирает одно из 16 расположений голосов (voicings): `0-3` - восходящий цикл тесных обращений; `4-7` добавляют drop-2; `8-B` добавляют drop-3; а `C-F` сочетают оба drop. Цикл продолжается через дополнительную октаву для трезвучий и power-аккордов, так что каждое значение отличается; большие значения становятся всё шире и менее привычными. Например, `CRD 4Y` - основной вид в drop-2, а `CRD DY` - первое обращение с обоими drop. У нижней или верхней границы таблицы высот голоса ограничиваются её диапазоном. Команда не сохраняется: записывайте её в каждой строке с аккордом. Каждая сгенерированная нота квантуется независимо, когда Scale активна, в режимах Quantizer и Note Lock. Она доступна только программным движкам; инструменты AY её игнорируют и остаются монофоническими.

#### Условия

По мотивам шведских «trig conditions» трекер поддерживает вероятности срабатывания и условия по модулю.

| FX | Значение | Смысл |
|---|---|---|
| `PRO` | `00-64` | Абсолютная вероятность срабатывания от `0%` до `100%` |
| `MOD` | `AB` | Срабатывает на итерации `A` из `B`; например `12`, `22`, `14`, `34` |

Счётчики `MOD` локальны для дорожки и фразы. Недопустимые сочетания, например `A` больше `B`, не срабатывают.

`MOD34` срабатывает на 3-м проходе каждого цикла из 4 проходов. `MOD1F` срабатывает на 1-м проходе каждого цикла из 16 проходов.

#### Скорость воспроизведения

Как и NerdSEQ, ChooChooTracker поддерживает независимую скорость воспроизведения для каждой дорожки.

`SPD` читает значение как байт со знаком. `00` - нормальная скорость, положительные значения ускоряют дорожку, отрицательные - замедляют. Настройка остаётся активной, пока другая команда `SPD` её не изменит.

| Значение | Скорость |
|---|---:|
| `00` | `x1` |
| `01` | `x2` |
| `02` | `x3` |
| `7F` | `x128` |
| `FF` | `/2` |
| `FE` | `/3` |
| `80` | `/129` |

Старые проекты без поддержки `SPD` со знаком сохраняют исходное соответствие `00-10`, поэтому играют так же, как были сохранены.

Очень большие множители могут превысить разрешение планировщика тиков трекера и не проверялись на реальном железе.

## 10. Mixer, Reverb и Delay

Mixer - самый левый из основных экранов. Он показывает загрузку CPU и предупреждения о клиппинге. Красный `!` в колонке **CLIP** отмечает дорожку, чей сухой сигнал вывел микс за безопасные пределы.

С его помощью можно балансировать 8 дорожек, формировать каждую дорожку Tilt EQ и отправлять звук на реверберацию или delay:

| Поле | Смысл |
|---|---|
| LVL | Уровень дорожки после движка, `000-100` |
| REV | Отправка на общую реверберацию Clouds, `000-100` |
| DLY | Отправка на общий пинг-понг delay, `000-100` |
| TLT | Tilt EQ дорожки, `00-FF`; `80` нейтрален, низкие значения подчёркивают бас, высокие - верха. Низкие значения вносят мягкий овердрайв. |
| M | `*` заглушает эту дорожку |
| S | `*` включает solo этой дорожки |

Микшер привязан к дорожкам, а не к инструментам. Если на дорожке меняется инструмент, её уровень, PAN, Tilt и отправки остаются за дорожкой. У инструментов тоже есть собственные **Vol** и **Pan** в диапазоне `00-FF` в верхней строке экрана Instrument. PAN инструмента применяется первым, затем PAN дорожки. Оба сохраняют существующую стереокартину в центре; при смещении влево или вправо они постепенно ослабляют противоположную сторону.

### Master FX

Пункт **MASTER FX** открывает подменю Insert FX с двумя слотами для всего
микса. Его эффекты работают после возвратов реверберации и delay, перед мастер-
громкостью. Выберите модуль, редактируйте его параметры или переводите в bypass точно так же, как для
вставки дорожки; нажмите **OPT**, чтобы вернуться в Mixer. Настройки Master FX сохраняются
вместе с проектом и не автоматизируются фразами, таблицами или модуляцией.

### Clouds Reverb

Используйте **SELECT + [UP]** из Mixer, чтобы открыть экран настроек реверберации.

- **Return**: уровень мокрой реверберации в мастер-миксе.
- **Time**: управление затуханием/временем, `00-FF`.
- **Damping**: поглощение высоких частот, `00-FF`.
- **Filter**: фильтр нижних частот, применяемый перед реверберацией.

Это секция реверберации Clouds, а не полноценный гранулярный процессор Clouds.

### Ping-pong Delay

Используйте **SELECT + [DOWN]** из Mixer, чтобы открыть Delay, затем **SELECT + [UP]**, чтобы вернуться. Reverb работает в противоположном направлении: **SELECT + [UP]** открывает его, а **SELECT + [DOWN]** возвращает в Mixer.

- **Return**: уровень мокрого delay.
- **To Reverb**: доля мокрого сигнала delay, отправляемая в общую реверберацию, `0-100%`.
- **Ticks**: время delay в тиках трекера (`9 ticks` = `1 доля` по умолчанию).
- **Feedback**: величина перекрёстной обратной связи, ограничена `95%`.
- **Filter**: фильтр нижних частот в тракте задержанного сигнала.

Первое повторение следует за стереовходом. Последующая обратная связь перекрещивается между левым и правым каналами.

## 11. Экран Project

Экран Project предоставляет команды **Load**, **Save**, **New**, **Export**, **Manage** и **Scale**, а также метаданные: имя файла, название и автор.

### Место экспорта (Export location)

Экспорт, стемы и bounce записываются в отдельную для каждого проекта папку внутри уже существующего каталога сэмплов приложения:

- **По умолчанию**: `<app folder>/samples/Exports/<project name>/`. Пока у проекта нет имени, папка называется `current-project`.
- В веб-версии по умолчанию используется `/user/samples/Exports/<project name>/`.
- В Android папка сэмплов находится внутри приватного рабочего пространства приложения.

Строка **Folder** на экране EXPORT показывает активное место назначения:

- Коснитесь **EDIT**, чтобы выбрать собственную папку в браузере папок. Выбранная папка используется ровно как выбрана (подпапка проекта не добавляется) и запоминается в настройках.
- **EDIT + OPT** (clear) возвращает место по умолчанию.

Когда именованный проект сохраняется под новым именем, папка экспорта по умолчанию переименовывается соответственно, сохраняя ранее экспортированные файлы вместе с проектом. Переименование не применяется к пользовательской папке, а автосохранение папку не переименовывает. Если папка с целевым именем уже существует, обе папки сохраняются. Если трекер потерял связь с папкой (например, после перезапуска), сохранение именованного проекта вместо этого переименовывает существующую папку `current-project`. Инструменты продолжают работать после переименования: пути загруженных сэмплов, указывающие в переименованную папку, обновляются автоматически.

**Load** также принимает файлы `.mid`/`.midi`, импортируя их как новый проект: ноты группируются по MIDI-каналам (один канал на дорожку, до числа дорожек), квантуются до 4 строк на долю и размещаются на одном инструменте AY по умолчанию - номера программ MIDI не имеют аналога в чиптюне, поэтому потом выберите настоящие инструменты. Используется только первый темп файла (одна глобальная частота тиков, без смены темпа по секциям). Строка **MIDI** на экране Export делает обратное: записывает ноты, громкость и темп/groove текущей аранжировки в стандартный MIDI-файл (одна MIDI-дорожка на дорожку трекера); инструменты [MIDI Out](#midi-out) и другие FX строк, кроме громкости и глобального groove, не имеют аналога в MIDI и не переводятся.

**Load** также принимает песни Dirtywave M8 (`.m8s`, прошивка 2.x-4.x), импортируя их как новый проект. Переносятся только структура и ноты (строки песни, цепочки с транспонированием, фразы с нотой, velocity и номером инструмента, note-off, темп и название песни); ноты сохраняют реальную высоту (M8 называет октавы на две выше: его `C-6` - это здесь `C-4`). Каждый инструмент, используемый во фразе, импортируется под именем инструмента M8. Инструменты M8 **MACROSYN** становятся инструментами Braids (47 форм - это модели Braids с теми же номерами; timbre, color, тип фильтра, частота среза, резонанс и pan переносятся, а кривая среза приблизительна). Инструменты **SAMPLER** становятся инструментами Sample: `.m8s` хранит только путь к WAV на карте M8, поэтому файл ищется в папке `.m8s` и её родительских (подойдёт копия структуры карты) и в вашей текущей папке сэмплов (работают и `Samples`, и `samples`); если файл не найден, инструмент сохраняет путь M8 и молчит. Импортированные сэмплы получают +24 полутона в настройке Pitch, так как M8 играет сэмпл на исходной высоте на две октавы ниже, чем это приложение. **FMSYNTH** становится инструментом Genesis FM (грубое приближение), **WAVSYNTH** и **HYPERSYNTH** становятся aChChid. **MIDI OUT** становится инструментом MIDI Out (канал, банк, программа и первые четыре номера CC). Другие типы (внешние) становятся инструментом AY по умолчанию - потом выберите настоящие звуки. FX и таблицы игнорируются.

На компьютере строка **M8S** на экране Export делает обратное, в ограниченном виде: коснитесь её и выберите существующий `.m8s` в качестве **шаблона** (запоминается до выхода, **EDIT + OPT** забывает его). Его песня, цепочки, фразы, темп и название заменяются, а всё остальное сохраняется как есть, за исключением того, что инструменты Braids записываются обратно как MacroSynth, а инструменты Sample - как Sampler (путь `/Samples/<file name>`: скопируйте туда WAV на M8 самостоятельно), при условии что в шаблоне есть инструмент такого типа, откуда можно скопировать остальные параметры. FX не экспортируются, а песню с фразой `FF` или выше экспортировать нельзя (в M8 255 фраз). Экспортированный файл пока не проверялся на настоящем M8. Подробности см. в [M8 songs](../m8s-format.md).

На компьютере key jazz позволяет вводить имя файла, название и автора прямо с клавиатуры вместо экранной виртуальной клавиатуры - см. [Key jazz](#key-jazz-только-на-компьютере).

### Scale / Quantize

Экран Scale управляет глобальным движком гаммы 12-TET. Строка **Mode** выбирает один из двух режимов:

- **Quantizer** (по умолчанию): ввод во фразах остаётся хроматическим; при включении ноты сразу перед попаданием в звуковой движок округляются вниз, поэтому смена основной ноты или гаммы перегармонизирует песню без правки её фраз.
- **Note Lock**: ноты, вводимые во фразы, при вводе привязываются к ближайшей ноте гаммы, так что записать можно только ноты гаммы. Новые вводы и понижения привязываются вниз; `EDIT + RIGHT` / `EDIT + UP` поднимают ноту до следующей ноты гаммы выше. На этом экране ввод всегда следует гамме проекта: смена основной ноты или гаммы сразу влияет на вновь вводимые ноты на включённых дорожках, а уже сохранённые ноты остаются нетронутыми. FX `SCL` в этом режиме недоступен, а любой уже записанный `SCL` игнорируется. Квантование простых нот при воспроизведении обходится (ввод уже заблокирован); квантование аккордов через `CRD` по-прежнему применяется.

Пока курсор стоит на **Mode**, строка состояния держит видимым фиксированное описание активного режима: `Quantizes notes on playback` для **Quantizer**, `Snaps sequencer to scale` для **Note Lock**. Переключение режима сразу заменяет текст; любое сообщение о действии заменяет его, пока не истечёт его время.

Оба режима используют общие основную ноту, гамму, редактирование нот **Custom** и флажки дорожек. Каждый из восьми флажков дорожек определяет, к каким дорожкам применяется режим. Движок гаммы обходится для таблиц высот не из 12 нот и для инструментов Sampler с режимом **Slice** EQUAL, AUTO или LAZY (их ноты выбирают слайсы хроматически начиная с C-0); ввод MIDI не входит в эту версию.

- **Linear pitch** выбирает режим таблицы высот. **Off** - значение по умолчанию и проверенная на железе настройка для правильного отслеживания октав у AY, Braids и Plaits.
- **Tick rate** задаёт тайминг трекера и показывает соответствующий BPM (`tick rate x 60 / 24`).
- ChooChooTracker сохраняет проекты как `.cct`. Этот формат несовместим с ChipNomad.

Используйте **Save** перед сменой типов инструментов или загрузкой другого проекта.

## 12. Settings

- **Repeat delay / speed** настраивают повтор при удержании кнопки.
- **Stick live mode** выбирает `HOLD`, `TOGGLE` или `FREE` для уже назначенной кнопки Stick live.
- **MIDI** открывает подменю [MIDI](#14-midi): выбор устройства и сопоставление каналов MIDI In с инструментами.
- **Synths** содержит **AY Quality**, **Sample dithering** и глобальные настройки **Braids BITS / DRFT / SIGN**.
- **Mixer** содержит **Mix volume** и **Tilt pivot** проекта в диапазоне `250-4000 Hz` (по умолчанию `1 kHz`), используемый всеми элементами Tilt в Mixer.
- **Graphics** содержит **Edit color theme**, **Load font**, **Persistent waveform**, **Track visuals**, **Waveform FPS** и активный рендерер (`GPU` или `Software`). **Waveform FPS** задаёт частоту обновления осциллографа инструмента и визуализаторов микшера от `01` до `60`. Track visuals выбирает **Detailed** (волна синтезатора и её наложения) или **Audio waveform** (реальный суммарный выход этой дорожки) независимо для каждой дорожки; аудиоволна сразу очищает любое прежнее наложение ADSR при запуске воспроизведения. Шрифты и темы ChipNomad должны работать.
- **Key mapping** настраивает управление.
- **Support report** записывает небольшой диагностический текстовый файл с версией приложения, платформой, настройками звука и загрузкой CPU, состоянием воспроизведения/переполнения и компактной сводкой проекта. В него не входят данные сэмплов и текст названия/автора проекта. В Android и Web открывается обычный процесс экспорта/скачивания; настольные и портативные сборки сохраняют `support-report.txt` в записываемую папку приложения.
- **Quit ChooChooTracker** выходит корректно.

**Graphics → Boot screen** выбирает **Original** (по умолчанию) или **Night**. Коснитесь EDIT
или используйте EDIT + направление, чтобы изменить; выбор сохраняется для следующего
титульного экрана. Night использует исходную железнодорожную сцену с более мягкими серо-голубыми тонами,
процедурный Млечный Путь с едва заметным мерцанием звёзд и редкими падающими звёздами.
Исходные пейзаж и поезд сохраняют свои циклы прокрутки.

## 13. Производительность и устранение неполадок

### CPU

Нагрузка на CPU зависит от активных движков и эффектов. Физические модели Plaits и Clouds Reverb тяжелее обычных голосов AY. Проверяйте производительность на целевой консоли, особенно при 8 голосах Plaits и двух активных отправках. Показание CPU около `100%` может вызывать треск или пропуски аудио-дедлайнов.

Индикатор CPU - сглаженная оценка времени аудио-рендеринга. Он не измеряет задержки до запуска аудио-callback или в аудиовыходе устройства, поэтому треск возможен даже при низком показании.

В Android аудиовыход теперь предпочитает AAudio, чтобы избежать периодического треска, наблюдавшегося с OpenSL ES на Pixel 7a. Этот буферизованный выход отдаёт приоритет стабильному воспроизведению и может добавлять некоторую задержку отклика. Холст трекера сохраняет полную компоновку 4:3 на квадратных и других необычных соотношениях сторон; неиспользуемое место показывается рамками, а не обрезкой колонок. Если треск сохраняется, сообщите песню, модель телефона, версию Android и то, используете ли вы динамик, наушники или Bluetooth.

Если вы сталкиваетесь с щелчками, сбоями или замедлениями, используйте **Settings > Support report** и приложите созданный `support-report.txt` к отчёту об ошибке. Если проблему вызывает конкретная песня, приложите и её `.cct`.

### Нет звука

Проверьте номер инструмента, состояние mute или solo дорожки, LVL дорожки, Mix volume приложения и огибающую инструмента. Для сэмплов проверьте, что исходный WAV всё ещё существует по сохранённому пути. В ArkOS нажмите **MENU + L3**, чтобы переключить отключение звука операционной системы. Если это не помогло, перезапустите железо и заново подключите аудиоинтерфейс.

### Управление ощущается неправильно

Отрегулируйте Repeat delay и Repeat speed в Settings. Если одно нажатие сдвигает дважды, проверьте, что за этим направлением закреплён только 1 физический элемент управления, и сообщите точный экран и сочетание.

## 14. MIDI

Компьютер и PortMaster. Settings > **MIDI** открывает это подменю: **MIDI In** / **MIDI Out** выбирают подключённое устройство, перебирая обнаруженные порты с `OFF` на обоих концах; для обоих направлений должно быть выбрано устройство. Выбор устройства действует в пределах сессии: он не сохраняется в settings.txt, поскольку положение порта в списке может меняться между перезагрузками или при подключении устройств в другом порядке. Кнопка **PLAY** приложения остаётся доступной на этом экране и запускает песню. В PortMaster подключите USB MIDI-устройство до запуска; операционная система консоли должна предоставлять его через ALSA.

- **Прослушивание звука с MIDI-клавиатуры**: при выбранном устройстве MIDI In игра нот на подключённой клавиатуре прослушивает инструмент на любом экране, так же как экранное сочетание **EDIT + PLAY** на экране [Instrument](#5-instruments). Это только прослушивание - ноты в песню не вводятся.
- **Channel mapping**: открывает список из 16 MIDI-каналов; назначьте каждому инструмент (по умолчанию `OFF`), чтобы ноты, полученные на этом канале, прослушивали этот инструмент независимо от того, какой выбран на экране Instrument - например, канал `01` -> инструмент `05`. Канал, оставленный на `OFF`, возвращается к текущему выбранному инструменту - исходному поведению. Это сопоставление сохраняется в settings.txt.
- **MIDI CC mapping**: связывает входящий контроллер с параметром инструмента, включая его **Volume**, или с глобальными элементами управления. Глобальные строки показывают `TRK 1`-`TRK 8` вместо инструмента и дают для дорожки **Mute**, **Solo**, **Volume**, **Reverb send** и **Delay send**; у **Song play/stop** цели нет. Новое сопоставление игнорирует CC, который его изучил или настроил, и вступает в силу при следующем физическом движении, поэтому настройка сопоставлений во время воспроизведения не может обнулить патч. Mute и solo используют `0-63` = off, `64-127` = on.
- **Управление внешним MIDI-устройством**: назначьте дорожке тип инструмента [MIDI Out](#midi-out) и задайте её Channel; запуск нот на этой дорожке отправляет настоящий MIDI на выбранное устройство MIDI Out вместо звука в самом ChooChooTracker.

## 15. Авторы и лицензии

ChooChooTracker - форк ChipNomad и сохраняет его подход к лицензированию MIT. Код Braids, Plaits, Plaits-Alt, Clouds DSP, производного от Warps DSP для MME и stmlib получен из открытых релизов Mutable Instruments под соответствующими уведомлениями MIT. Plaits-Alt взят из форка Plaits Lab репозитория lylepmills/eurorack; к нему применяются сохранённые уведомления об исходном коде. Движок aChChid использует Open303 Робина Шмидта (Robin Schmidt), copyright 2009, по лицензии MIT. Bogie и Sintered - оригинальные встроенные реализации. MIDI-ввод-вывод использует RtMidi Гэри П. Скавоне (Gary P. Scavone) по лицензии в стиле MIT. Точное авторство см. в прилагаемых файлах лицензий.

## Эффекты-вставки дорожки (Track insert effects)

У каждой из восьми дорожек два последовательных слота, **TF1 → TF2**. Из Instrument
обычным жестом Shift+Вверх откройте MOD, затем ещё раз Shift+Вверх для **F: Insert
FX**. Shift+Вниз возвращает в MOD. OPT+Влево/Вправо выбирает дорожку (1-8), не
меняя селектор инструмента. Заголовок модуля открывает существующий селектор;
bypass сохраняет модуль, настроенные значения и автоматизацию. Параметры - это
значения-байты: левая колонка 1-4, правая колонка 5-8. Контекстный текст показывает полные названия и
декодированные значения. Старые проекты загружаются с обоими слотами в OFF.

Панель навигации держит полную колонку F-M-I-P видимой на всех
экранах инструмента, включая Insert FX и instrument pool, и подсвечивает
текущий экран.

| Модуль | Параметры по порядку |
| --- | --- |
| Work Compressor | Threshold, Attack, Release, Makeup, Ratio, Detector source, Detector filter, Mix |
| Airwindows Distortion | Input, Mode, Output, Mix |
| Airwindows StereoDoubler | Detune, Mix |
| TAPESCAM | Input, Drive, Color, Wobble, Tone, Output |
| OTT (Rui-727) | Depth, Time, Upward, Downward, Input, Output |
| Chorus | Rate, Depth, Tone, Mix |
| Flanger | Rate, Depth, Feedback, Mix |
| Phaser | Rate, Depth, Feedback, Mix |
| Rotary | Speed, Depth, Drive, Mix |
| Saturation | Drive, Tone, Level, Mix |
| Bitcrusher | Bit depth, Rate reduction, Tone, Mix |
| Destruction | Mode, Amount, Tone, Mix |
| Parametric EQ | Low gain, Low frequency, Mid gain, Mid frequency, High gain, High frequency |

Непрерывные элементы управления используют 00-FF, включая допустимый нуль и максимум FF. У
биполярных элементов точная нейтраль находится на 80. Режимы Distortion: 00 Density, 01 Drive,
02 Spiral, 03 Mojo, 04 Dyno. Отношения Compressor 00-07 равны 1,5, 2, 3, 4, 6, 8, 16,
20:1; источники детектора 00-02 - стереовход, левый, правый. Detector filter 80
нейтрален, ниже - фильтр нижних частот, выше - фильтр верхних частот. Внешний/межканальный сайдчейн
не предусмотрен. В любом слоте может быть любой модуль; повторяющиеся модули независимы.
Chorus, Flanger, Phaser и Rotary используют мягкие значения модуляции по умолчанию. Rotary Speed
использует полный диапазон **00-FF**: **00 = 0,01 Hz** (один оборот за 100 секунд),
**FF = 25 Hz** (прежний максимум Chaos). Экспоненциальная шкала даёт более точный
контроль над медленным движением LFO. Новые вставки Rotary по умолчанию стоят на **8F**, около
0,8 Hz. Это заменяет четыре дискретных значения скорости; существующие настройки Rotary
и автоматизацию скорости F11/F21 нужно перенастроить на новую шкалу (прежние Slow/Fast/Hyper/
Chaos примерно соответствуют **8F/CB/E7/FF**). Остальные параметры не меняются.
Разрядность Bitcrusher - от 4 до 16 бит, а
понижение частоты - от 1x до 32x. Режимы Destruction: Fold, Clip и Crush.
Saturation и distortion включают элементы управления выходным уровнем или mix для балансировки
с необработанным сигналом.
У Parametric EQ полочные фильтры буст/срез 24 dB на 60-500 Hz и 2-14 kHz, плюс
колокол с фиксированной добротностью 0,9 на 250 Hz-5 kHz. Его регуляторы усиления нейтральны на 80; при
трёх нейтральных это точный bypass. Активный EQ использует прозрачное мягкое колено (soft knee) выше
полной шкалы и достигает максимума 1,5, чтобы сдерживать экстремальные подъёмы.

Уровень дорожки и tilt EQ идут перед вставками, поэтому оба влияют на сигнал, поступающий в
компрессию и дисторшн. Все голоса/ноты аккордов дорожки питают одну цепочку
вставок. Отправки на реверберацию и delay получают её выход. Общие эффекты, возвраты,
мастер-регуляторы и mute/solo сохраняют прежнее поведение. Вставки не
обрабатывают звук внешних MIDI-устройств.

Команды вставок используют **F11-F18** для TF1 и **F21-F28** для TF2. Выбор FX
в roll и всплывающее окно Phrase/Table предлагают только параметры, используемые настроенными вставками
выбранной дорожки. Окно группирует их как **TF1: название эффекта** и
**TF2: название эффекта**; слоты OFF скрыты. Вставки в bypass остаются редактируемыми.
Во всплывающем окне FX для Phrase и Table описание следует за слотом вставки
выбранной дорожки: оно показывает модуль, название параметра, декодированные границы диапазона и
сохранённое базовое значение. Существующие команды песни сохраняются, если смена модуля делает
их неиспользуемыми; при открытии их селектора курсор встаёт на доступный элемент управления.
Во время редактирования значения нижняя подсказка показывает его декодированное значение и единицы.
Любая колонка FX в Phrase или Table может адресовать любой из слотов; сетка Phrase сохраняет свои
три колонки. Эти абсолютные значения времени исполнения сохраняются между нотами, инструментами,
фразами, цепочками и обычными циклами. Новое воспроизведение/жёсткая остановка их сбрасывает. Редактирование
базового значения на странице F очищает переопределение только этого параметра. MOD действует на
эффективное базовое значение/значение автоматизации, не сохраняя свои смещения. Выбор нового
модуля восстанавливает значения по умолчанию и очищает переопределения этого слота. Bypass сохраняет
существующую автоматизацию, приостанавливая обработку после короткого затухания.

**Адреса относятся к слотам дорожки и позициям параметров, а не к именованным эффектам.** Фраза,
повторно используемая на другой дорожке, использует модули этой дорожки. Смена модулей может
изменить смысл команды; команды не переписываются. Адреса OFF/неиспользуемые
безопасно ничего не делают и остаются нетронутыми в сохранённых данных Phrase/Table.

Селектор MOD инструмента добавляет категорию Insert FX. Источники каждого инструмента
управляют вставками той дорожки, которая его играет, включая комбинированный сигнал аккорда.
Один и тот же инструмент на двух дорожках влияет на независимые цепочки. Применяются существующий тайминг
источников, величины со знаком, правила комбинирования источников, режимы стиков и запись
движения. Дискретные элементы управления квантуются и ограничиваются допустимыми вариантами. Нового
банка модуляции, принадлежащего дорожке, нет.

Makeup у Compressor начинается с 0 dB. OTT начинается примерно с 25% depth, 25%
upward, 50% downward, 0 dB на входе и -3 dB на выходе. Пороги полос, усиления и
частоты разделения остаются на родных значениях Rui-727; Depth - его регулятор wet/dry.
TAPESCAM сохраняет родные вспомогательные значения: новая/быстрая лента, шум и
компрессия выключены, расширение включено. Следите за существующими индикаторами клиппинга при добавлении
drive/gain. Переходы слотов используют ограниченные 5-мс затухания через сухой звук.

Сохранения хранят идентификаторы модулей, bypass и настроенные байты в необязательных
версионных разделах `Track inserts: 1,8,2` и `Master inserts: 1,2`. Переопределения времени исполнения
и истории DSP не сохраняются.
Делайте резервные копии, прежде чем открывать сохранения со вставками в старых сборках. Авторство DSP,
редакции исходного кода и адаптации указаны в `chipnomad_lib/external/insert_fx/SOURCES.txt`;
полные уведомления MIT поставляются в `licenses/INSERT_FX.txt`.

На R36H при 48 kHz измеренная пара вставок на одной дорожке занимала примерно 4-5%
реального времени для Compressor, 6% для Distortion, 18% для Doubler, 16% для TAPESCAM
и 24% для OTT, не считая стоимости синтезаторов и общих эффектов. Шестнадцать активных
экземпляров Doubler, TAPESCAM или OTT превысили реальное время. Модуляция звуковой частоты добавляет
дополнительную нагрузку. Начинайте с нескольких вставок, следите за перегрузкой аудио и переводите
неиспользуемые слоты в bypass; шестнадцать доступных позиций - не гарантированный бюджет CPU.

Страница Insert держит подсказку выбранного поля видимой после отпускания кнопки;
временные уведомления всё же могут занять её место. Селектор модулей показывает для каждого
модуля тип эффекта и исходный проект рядом с названием.

### Встроенные инструменты OPLL и VRC7 (разработка)

В селекторе Instrument Type есть группа FM с **OPLL / MSX** (YM2413)
и **VRC7** (DS1001). Теперь каждый предлагает **73 программы** в прокручиваемых списках Bank / Preset:
исходные 15 тембров, 40 дополнительных различающихся тембров из таблиц
YM2413/VRC7/YMF281B проекта emu2413 и 18 двухоператорных программ, написанных для ChooChoo.
Точные дубликаты байтов тембра в каждом движке опускаются. Дополнительные
палитры используют программируемый слот тембра чипа; они не расширяют физическую
ROM. Программа ноль обозначает пользовательский тембр. EDIT + влево/вправо выбирает
предыдущий или следующий пресет в рамках фильтра банка. Fine ct настраивает строй
от -100 до +100 центов.

В списке программ EDIT + PLAY прослушивает выделенный звук; отпустите
кнопки, чтобы остановить. EDIT подтверждает, OPT отменяет. Просмотр/прослушивание не меняет
инструмент, таблицу или песню. Обычный жест прослушивания на странице Instrument
продолжает работать после выбора. Родные огибающие чипа обеспечивают attack/release;
необязательный Amp env добавляет программный ADSR (см. Элементы управления встроенных чипов ниже).
Полного редактора операторов нет.

Новые инструменты хранят все восемь родных байтов тембра, банк/имя, программу и точную подстройку в
файле песни/инструмента. Файлы с этими типами используют формат 7.0 и требуют
этой сборки или новее. Более ранние форматы остаются читаемыми; песни без этих типов
по-прежнему сохраняются как 5.0. Ритмические программы отложены. Расширенная библиотека
проверена на хосте; прослушивание человеком и новая проверка на портативной консоли ещё впереди.

### AdLib / OPL2 и OPL3 (разработка)

FM также включает AdLib / OPL2 (YM3812) и OPL3 (YMF262). Bank фильтрует
заводской список; Preset открывает группы по категориям и вид All. EDIT + PLAY прослушивает
перед выбором, EDIT выбирает, OPT отменяет, а EDIT + влево/вправо на Preset
загружает предыдущую/следующую подходящую запись. Fine ct настраивает локальный строй. Mode показывает
2 оператора, 4 оператора или Dual voice. OPL2 скрывает несовместимые патчи OPL3;
OPL3 может играть общую двухоператорную коллекцию.

Заголовки окон банка и пресета указывают текущий движок. Смена движка или
слота инструмента сбрасывает фильтр банка на **All banks**, включая переключение
между совместимыми движками AdLib и OPL3. Возврат из окна в том же
слоте сохраняет выбранный фильтр. Отмена импорта банка DX7 восстанавливает
предыдущий фильтр.

Подтверждение пресета также публикует правки, сделанные при отпускании кнопки, на следующем
тике интерфейса/звука. Играющим песням больше не нужно ещё одно нажатие кнопки или
перезапуск транспорта, чтобы получить этот патч. Выход по-прежнему следует настроенному аудиобуферу
и поведению огибающей/перезапуска движка.

Заводская коллекция содержит 697 исходных записей из The Fat Man 2-op,
The Fat Man 4-op и DMXOPL3, с 589 нормализованными уникальными идентичностями патчей.
Псевдонимы сохраняют исходные названия и авторство. Исходные уровни операторов, флаги
глубины LFO, смещения нот, фиксированные высоты перкуссии и строй двойных голосов
сохраняются. Громкость трекера использует программную амплитуду; она не воспроизводит
кривые громкости и политики смещения velocity исходных MIDI-плееров. Оценки
длительности release из источника не обрывают тянущиеся ноты. У некоторых эффектов
медленная атака: удерживайте Seashore, а не ждите, что короткий щелчок его раскроет.

Заводские ресурсы лежат в `instruments/chips` рядом с существующей библиотекой
инструментов, а уведомления - в `licenses/chip-banks`. Выбор пресета оставляет таблицу
слота и вставки дорожки без изменений. Заново сохранённые файлы используют 7.0 и
встраивают полный тембр. Заводской звук автоматически проверен на хосте и на ARM64; прослушивание
человеком остаётся впереди.

### Встроенные инструменты Sega PSG и Game Boy (разработка)

CHIP теперь включает Sega PSG, GB Pulse и GB Noise. Sega использует мастер-тактовую частоту NTSC
и 16-битную обратную связь шума, включая шум, получаемый из канала тона.
Его **Bass range: Extended** по умолчанию при необходимости понижает виртуальную тактовую частоту, чтобы
играть ниже предела делителя чипа, около 109 Hz. Это сохраняет A-2, G-2
и F-2 различимыми. Выберите **Chip** для исходного диапазона, где более низкие ноты
сходятся к пределу делителя. Шум с фиксированной частотой сохраняет исходную тактовую частоту;
шум, получаемый из тона, следует расширенной высоте. Старые инструменты Sega загружаются с
включённым Extended; настройка сохраняется вместе с инструментом.
Инструменты GB используют регистры импульса/шума DMG; канал волны Game Boy не
предоставляется. Их авторские списки пресетов теперь содержат **24, 24 и 28** пресетов
соответственно. Дополнения охватывают связанный/периодический шум Sega, свипы высоты GB,
короткие ударные, металлический шум, дроны и нарастания. Это оригинальные программы,
а не звуки, извлечённые из игр.
Страница предлагает родные элементы управления режимом/duty/шириной, огибающей/свипом/шумом,
где применимо, а также программный ADSR амплитуды. Они сохраняются в родных файлах версии 6.
Автоматические проверки производительности/звука на ARM64 проходят в пределах заявленных
нагрузок; прослушивание человеком остаётся впереди.

### DX7 FM (разработка)

Выберите **Type → FM → DX7 FM**; DX7 - седьмая запись, после Arcade / YM2151.
DX7 FM использует шестиоператорное ядро MSFA. Существующая страница FM предлагает
Bank, Preset и Fine ct рядом с общими настройками инструмента. Просмотр пресетов
использует списки по банкам/категориям. Удерживайте EDIT+PLAY, чтобы услышать выделенный звук; отпускание
останавливает прослушивание. Один EDIT подтверждает при отпускании; OPT отменяет. Загрузка звука
копирует его полный патч, не меняя таблицы трекера и FX вставок дорожки.

Заводской каталог сейчас содержит **67 различных патчей параметров DX7**:
31 оригинальный музыкальный звук OpenDX7, четыре уникальных звука YSE CC0 (его 32 слота банка
повторяют эти четыре под разными именами) и 32 патча, написанных для ChooChoo.
Здесь «оригинальный» означает программы параметров, созданные для этого проекта; это не
означает оригинальное заводское содержимое Yamaha. YSE поставляется как четыре звука, а не 32
искусственно различающихся имени.
Категории описывают проверенный замысел звукового дизайна. Неоднозначные названия остаются в
Unsorted. Численные проверки игровой пригодности пройдены; приёмка на слух
впереди. Отдельная цель в 1000 звуков, свободных для распространения, не достигнута.

Для постоянной личной библиотеки положите файлы `.syx` в
**`instruments/banks/dx7/`** рядом с существующей библиотекой инструментов. Подпапки
поддерживаются. Откройте **DX7 → Bank**: каждый файл появляется как именованный банк, готовый для
просмотра в Preset. Откройте Bank заново после добавления или удаления файлов; преобразование или
шаг Load Instrument не нужны. Стандартный оригинальный банк DX7/TX7 содержит
**32 голоса**. Файл с четырьмя сообщениями банка появляется как четыре пронумерованных банка
(всего 128 голосов). Файлы с одним голосом тоже принимаются. Нативное приложение
читает эту папку; браузерная версия читает свою виртуальную файловую систему, а не произвольные
папки на компьютере.

Повреждённые или неподдерживаемые файлы пропускаются с отображением их числа на экране; корректные банки остаются
доступными. Сканирование ограничено 2048 файлами, 1 МиБ на файл, 64 МиБ всего,
60 000 голосов и восемью уровнями вложенных папок. Символические ссылки игнорируются.
Выбранный патч принадлежит инструменту: удаление его исходного банка не может
изменить сохранённую песню. Полная библиотека для просмотра остаётся в этой папке и
не копируется целиком в каждый проект.

LOAD INSTRUMENT также принимает дампы `.syx` оригинальных DX7/TX7 с одним голосом и банков по 32 голоса,
включая ограниченные последовательности этих поддерживаемых сообщений. Он проверяет
разметку, число байтов, семибитные данные, контрольные суммы, диапазоны параметров и размер файла
перед открытием импортированного банка в том же браузере FM. Выбор патча
подтверждает его; отмена сохраняет текущий инструмент песни. Этот ярлык прямого импорта
хранит свой список просмотра на время сессии; для постоянного просмотра используйте папку банков выше.
Сохраните песню или `.cni`, чтобы сохранить выбранные/отредактированные патчи. Дампы без заголовка,
с неверными контрольными суммами, исполнения/расширения DX7II и другие семейства Yamaha
отклоняются. Импорт никогда не отправляет MIDI-сообщения внешнему оборудованию.

CNI и версия 6 проектов хранят все 155 исходных байтов голоса, полное отображаемое
имя, родную скорость удара, точную подстройку и идентификатор источника. Песням не нужен
внешний банк для повторного открытия. Старые релизы ChooChoo не могут читать эти файлы
версии 7; проекты, где их нет, по-прежнему сохраняются как версия 5. Родная velocity по умолчанию
равна 100; громкость трекера - усиление после синтеза и не перезапускает огибающую.
Огибающие операторов, режим фиксированной частоты, keyboard scaling, огибающая высоты и
LFO остаются родным поведением патча. Необязательный общий ADSR амплитуды FM формирует
их суммарный выход, не заменяя огибающие операторов.

У каждой партии дорожки один LFO и четыре отдельно принадлежащих слота аккордовых голосов, в соответствии
с существующей политикой аккордов/замены трекера. Дорожки не делят состояние нот.
Note-off отпускает родные огибающие; cut/panic их очищает. Скалярное ядро MSFA
использует кванты по 64 сэмпла при фиксированной внутренней частоте 44,1 kHz, с потоковым FIR до
выходной частоты. Таблицы поиска инициализируются один раз вне аудио-рендеринга, чтобы
одновременные офлайновые и живые рендереры не могли влиять на частоту друг друга. События
вступают в силу на следующем внутреннем кванте (до 1,45 мс), после чего идёт групповая задержка FIR
около 0,25 мс. Буферизованные сэмплы сохраняются между callback. Это линия MSFA Modern, а не
заявление о побитовой идентичности железу DX7 или об эмуляции Dexed Mark I.
DX7 ограничен **16 активными нотами на всю песню**, включая хвосты release, при сохранении
четырёх принадлежащих слотов аккорда на дорожку.
При превышении бюджета сначала удаляются хвосты release, затем самые тихие удерживаемые ноты,
затем свежие атаки. При равных атаках корневые ноты сохраняются между дорожками раньше расширений
аккорда, с устойчивым разрешением ничьих по слоту/дорожке. Эта политика применяется на всех
платформах, поэтому одна и та же песня получает одинаковое ограниченное распределение нот. Она
не меняет полифонию других инструментов. Прослушивание пресета отключено во время воспроизведения.
Предел выбран по измерениям на R36H и проверен при смешанном воспроизведении.

#### Редактор операторов FM

У инструментов Genesis FM, Arcade FM, OPL2, OPL3, OPLL и VRC7 есть кнопка **EDIT**
справа от Fine ct. Она открывает таблицу параметров патча:

- Genesis FM / Arcade FM: algorithm, feedback, pan, AMS, PMS, маска операторов и
  настройки LFO, затем MUL, DT, TL, KS, AR, D1R, D2R, RR и D1L для четырёх
  операторов, плюс SSG (Genesis) или DT2 и AM (Arcade).
- OPL2 / OPL3: feedback, connection и pan для каждого голоса, deep vibrato и tremolo,
  затем MUL, TL, AR, DR, SL, RR, waveform, KSL, VIB, TRM, SUS и KSR для каждого
  оператора. На OPL3 здесь можно менять режим (2op, 4op, dual).
- OPLL / VRC7: регистры пользовательского тембра (feedback, MUL, TL, KSL, AR, DR, SL,
  RR, waveforms, AM, VIB, EG, KSR). Редактирование пресета ROM превращает его в
  «Custom».

Влево/Вправо и обычные клавиши редактирования меняют значения; инструмент продолжает играть
как обычно, так что изменения слышны. Строка состояния описывает параметр под
курсором. OPT или Left+Shift возвращает на экран инструмента. У DX7 и SID
редактора операторов нет.

Genesis FM (YM2612) и Arcade FM (YM2151) теперь используют тот же браузер FM Bank/Preset,
то же прослушивание EDIT+PLAY, то же подтверждение/отмену и те же элементы точной подстройки. У Genesis теперь
**73 пресета**: исходные 24 и 49 поддерживаемых мелодических программ из банка CC0
16-Bit FM Music Station от NeoSoundFonts. У Arcade **81 пресет**: исходные
24 и 57 поддерживаемых звучащих программ из коллекции YMulator-Synth под GPLv3.
Исходная пара ChooChoo использует общие базовые рецепты; новые
исходные коллекции дают отдельные палитры. Это именованные коллекции звукового дизайна,
а не заявленные воссоздания конкретных саундтреков игр. Неподдерживаемые смещения нот,
фиксированные клавиши перкуссии, настройки шума аркадных автоматов и беззвучные исходные программы
записаны как исключения в `expansion-manifest.json`. Их полные настройки четырёхоператорного патча, огибающей,
LFO, стерео и строя передаются внутри инструментов и песен версии 6.
Родная огибающая чипа управляет release; обычные усиление и высота трекера
её не перезапускают. Выход ЦАП Genesis использует блокировщик постоянной составляющей на 20 Hz. Режим шума и
режим особой частоты канала 3 выходят за рамки этой реализации инструмента.

Для локального внешнего банка используйте `tools/chip_banks/import_bank.py SOURCE --output
NEW_DIRECTORY --writer tracker/build/tests/chip_factory`. Он принимает строгий
42-байтовый TFI, текст VOPM OPM, проверенный формат WOPLX и оригинальный SysEx DX7.
Загрузите полученные файлы `.cni` через Load Instrument. Пользовательские импорты хранятся
отдельно от распространяемой заводской библиотеки. Файлы OPM с включённым шумом,
ненулевыми данными частоты шума или частичной панорамой отклоняются с пояснением;
значения pan VOPM 0/64/127 становятся левый/оба/правый. Бинарный WOPL не поддерживается.
Общий каталог FM содержит **1064 записи**: 697 OPL, 67 DX7, 146
OPLL/VRC7, 73 Genesis и 81 Arcade. Ещё 76 файлов открывают пресеты Sega/Game Boy
через обычный файловый браузер, итого **1140 поставляемых встроенных пресетов**.
Редакции исходников, хеши, полные уведомления и исходные данные
новых коллекций приложены в `licenses/chip-banks/expansion`.

### Переносимые заводские коллекции и пресеты USER

Инструменты встроенных чипов используют **Bank:** для выбора ALL, включённой коллекции или
USER. **Preset:** выбирает звук внутри этой выборки. Удерживайте EDIT и нажимайте
Влево или Вправо на любой из строк, чтобы перебирать; короткое касание EDIT открывает её селектор.

Включённые коллекции - это ZIP-пакеты в `instruments/FACTORY/`. Файлы USER кладутся
в `instruments/USER/<engine>/`: `dx7`, `opll`, `vrc7`, `opl2`, `opl3`,
`genesis`, `arcade`, `sid`, `sega`, `gb-pulse` или `gb-noise`.
Просматривайте папки напрямую или кладите туда ZIP с совместимыми пресетами. ZIP остаются
нетронутыми на диске. Все эти папки принимают совместимые файлы `.cni`; CNI -
переносимый формат инструментов ChooChoo/ChipNomad, а не стандарт производителя чипов.
Браузер USER также читает следующие исходные форматы, в том числе внутри ZIP:

| Папка USER | Дополнительные форматы |
| --- | --- |
| `dx7` | Yamaha DX7/TX7 `.syx`, одиночные голоса и банки по 32 голоса |
| `genesis` | `.tfi`, DefleMask `.dmp`, Furnace `.fui` |
| `arcade` | банки VOPM `.opm`, DefleMask `.dmp`, Furnace `.fui` |
| `opl2`, `opl3` | `.wopl`, `.opli`, `.woplx`, `.sbi`, Furnace `.fui` |
| `opll`, `vrc7` | пользовательские патчи Furnace `.fui` и фиксированный выбор из ROM |
| `sega`, `gb-pulse`, `gb-noise` | Furnace `.fui`, DefleMask `.dmp` |
| `sid` | GoatTracker 2 `.ins` (GTI5), Furnace `.fui` |

Банк раскрывается в совместимые голоса. Неподдерживаемые файлы или возможности сообщают
причину; несовместимые голоса в смешанном банке исключаются, а их исходные
номера остаются стабильными. Загрузка транзакционна: отклонённый пресет оставляет
текущий инструмент неизменным. Исходные пресеты заменяют таблицу трекера инструмента
пустой, кроме SysEx DX7, который сохраняет существующую таблицу.
CNI восстанавливает свою сохранённую таблицу. Загруженные патчи принадлежат песне и продолжают
работать после перемещения или удаления исходного пакета.

Банки WOPL могут содержать неиспользуемые слоты без явного признака пустоты. Браузер
опускает безымянные слоты, у которых активные операторы полностью ослаблены и нет
attack. Безымянные играбельные голоса остаются доступными как `Program N [Bbank]` или
`Drum N [Bbank]`, по исходным номерам программы и банка, отсчитываемым от нуля.
Безымянный одиночный инструмент OPLI использует имя своего файла. Именованные беззвучные патчи
сохраняются.

Поддержка Furnace охватывает устаревшие версии с одним инструментом 29-112 и основанные на функциях
версии `FINS` 127-251. Поддержка DefleMask охватывает инструменты версии 11 для OPN, OPM, Sega PSG
и Game Boy. Это импорт инструментов, а не полноценные
проигрыватели трекеров: анимированные макросы FM/операторов, настройки LFO FM исходной песни, сэмплы,
последовательности аппаратных команд Game Boy, относительные макросы pulse/filter SID и зависимости
ring/sync SID сейчас отклоняются. Постоянный выбор ROM для OPLL
поддерживается; VRC7 использует собственную ROM для этого выбора. Файлы SID-Wizard `.swi` и музыкальные файлы
SID (`.sid`) в этой сборке не являются импортом инструментов.

Поддерживаемые последовательности PSG/GB/SID хранятся в патче и воспроизводятся на 60 Hz для
Furnace/DefleMask и на 50 Hz для GoatTracker. Эти файлы не несут полной конфигурации воспроизведения
песни: используйте исходный трекер, если нужны частота тиков,
маршрутизация каналов, поведение hard-restart или настройки совместимости, специфичные для песни. Для Sega PSG макрос duty выбирает голос шума; без него импорт
использует голос тона. Файлы Game Boy нужно класть в нужную папку pulse или
noise. Импортированные последовательности пока остаются встроенными данными воспроизведения; страница
инструмента редактирует базовые параметры, а не таблицы исходного трекера.

Перебор пресетов USER продолжается через файлы, папки, банки и ZIP-пакеты в
обоих направлениях и замыкается на концах. Повторное открытие браузера USER следует
текущему выбору. ALL включает звуки USER в Unsorted для движков
с категориями; USER остаётся отдельным выбором верхнего уровня. Sega PSG и Game Boy используют
плоские списки ALL/Factory и иерархический браузер USER, без панели
Unsorted. Старые файлы DX7 в `instruments/banks/dx7/` остаются доступными в USER.

Движок показывает только совместимые включённые коллекции. Factory Presets
объединяет включённые наборы тембров OPLL/VRC7 для выбранного движка; DX7 объединяет
оригиналы ChooChoo и YSE. Скачанные именованные коллекции остаются отдельными.
Fat Man 2-op указан в OPL2, а Fat Man 4-op - в OPL3. Совместимые файлы
CNI для OPL2 по-прежнему можно использовать в папках USER для OPL3.

Выход встроенных движков использует фиксированную измеренную компенсацию усиления, а не
нормализацию по пресетам. Поэтому существующие песни на встроенных инструментах могут звучать
на другом уровне; проверьте баланс сохранённых миксов. Метод калибровки
и границы описаны в `scripts/README_MEASURE.md`.

`native-chip-audition.cct` даёт короткое последовательное прослушивание
тринадцати исходных заводских банков. Каждая секция использует свой собственный инструмент, поэтому проект работает
и при удалённой папке пресетов. Более длинные WAV банков (игнорируются Git) и измеренные уровни
перечислены в `docs/chip-preset-auditions.tsv`; субъективное прослушивание ещё впереди.

### Элементы управления встроенных чипов (Native chip controls)

Превью осциллограмм встроенных инструментов обновляются при перерисовке их элементов управления.
Инструменты FM могут накладывать свою необязательную кривую Amp env; SID сохраняет превью осциллограммы
без этого наложения, свойственного только FM, в том числе при просмотре банков и пресетов.

Все семь движков FM предлагают **Bright**, **Feedback** и **Amp env**. Bright
меняется от -63 до +63, при нуле патч сохраняется; он меняет уровни модулирующих
операторов, сохраняя уровни несущих. Слышимый эффект зависит от
алгоритма. Feedback по умолчанию - **Preset**, либо переопределяет родную обратную связь
значением 0-7. Эти элементы управления не перезаписывают сохранённые родные байты операторов.

Amp env по умолчанию - **Bypass**. Выберите **ADSR**, чтобы добавить attack, decay, sustain,
release и форму вокруг родного звука. A/D/R используют общий квадратичный диапазон 0-5 секунд;
sustain идёт от тишины до полного уровня. Родные огибающие по-прежнему
работают, поэтому эта огибающая не может продлить звук за его родной release. Просмотр
пресетов сохраняет элементы управления амплитудой FM и тембром слота. Все голоса FM также используют
переход 3 мс при начале/перезапуске и сглаживание усиления трекера 1 мс, в том числе
когда Amp env в bypass. Hard cut/panic остаётся мгновенным.

Следующие FX фраз также доступны как поддерживаемые назначения Modulation и записи движения.
Значения в колонке FX шестнадцатеричные. Настройки применяются к воспроизведению,
не меняя сохранённый инструмент. Родные элементы свипа и огибающей GB
фиксируются при следующем запуске ноты; duty/ширина и частота шума могут меняться вживую.

| Движки | FX | Элемент управления |
|---|---|---|
| Native FM | `OL1`-`OL6` | Абсолютные выходные уровни операторов: модулятор OPLL/VRC7 и OPL `00-3F`; несущая OPLL/VRC7 `00-0F`; Genesis/Arcade `00-7F`; DX7 `00-63` (0-99). Больше значит громче выход. Появляются только поддерживаемые операторы. |
| OPLL/VRC7/OPL2/OPL3 | `OAR`, `ODR`, `ORR`, `OSL` | Attack, decay, release и ослабление sustain оператора 1, `00-0F`. |
| OPLL/VRC7/OPL2/OPL3/Genesis/Arcade | `OMU 00-0F` | Множитель частоты оператора 1. |
| Genesis/Arcade | `LFR` | Частота родного LFO: Genesis `00-07`, Arcade `00-FF`. |
| Arcade | `LAD`, `LPD 00-7F` | Раздельные глубины LFO по амплитуде и по высоте. |
| Genesis/Arcade | `LAS`, `LEN` | Родная чувствительность к амплитуде `00-03` и включение LFO `00-01`. |
| Genesis/Arcade | `LPS 00-07` | Родная чувствительность к высоте. |
| SID | `SAT`, `SDE`, `SSU`, `SRL 00-0F` | Родные attack, decay, sustain и release. Значения времени растут к `0F`; sustain растёт к полному уровню. |
| SID | `SPR 01-10` | Частота молчащего партнёра от 1× до 16×; влияет на кольцевую модуляцию и жёсткую синхронизацию. |
| Все native FM | `FBK 00-07` | Абсолютная родная обратная связь, инициализируется из инструмента. |
| Все native FM с включённым Amp env; Sega/GB | `EAT`, `EDC`, `ESU`, `ERL`, `ESH 00-FF` | Attack, decay, sustain, release, форма. Они не включают отключённый (bypass) усилитель FM. |
| Sega PSG | `CMD 00-02`, `CNR 00-03` | Тон / белый шум / периодический шум; три фиксированные частоты шума или частота, получаемая из тона. |
| GB Pulse | `CMD 00-03` | Родной duty импульса. |
| GB Noise | `CMD 00-01`, `CND 00-07`, `CNS 00-0D` | Ширина шума, делитель тактовой частоты и сдвиг. |
| GB Pulse | `CSP 00-07`, `CSS 00-07`, `CSD 00-01` | Период свипа, сдвиг, направление вниз. |
| GB Pulse / Noise | `CEI 00-0F`, `CEP 00-07`, `CED 00-01` | Начальный уровень родной огибающей, период, направление вверх. |

Выбор нативных FX использует инструмент из колонки `I` строки фразы или
активный инструмент, найденный просмотром назад, когда `I` пуста. Окно FX
показывает краткое описание элемента управления, его текущее значение в пресете и допустимый
диапазон команды в компактном блоке. Выбор другого
нативного эффекта начинается с этого значения; повторное открытие того же эффекта сохраняет его
изменённое значение. Выделение из нескольких строк определяет инструмент каждой строки отдельно.
Таблицы используют контекст своего инструмента. Правки нативных значений останавливаются на допустимых
границах, включая duty, шум, свип, ADSR, feedback и уровни операторов.
Значения шестнадцатеричные: например, максимум DX7 `63` означает 99 в десятичной системе.

Эти команды FM используют абсолютные родные значения. Команды операторов всегда нацелены на
оператор 1; `OMU 03` выбирает его множитель 3. Специфичные для трекера элементы управления DX7 -
уровни операторов и feedback. Preset/Range сохраняет свой информационный цвет;
заголовки и описания следуют тем же цветам, что и FM Feedback.

Живая модуляция сохраняет полный набор нативных назначений для фиксированных операторов.
Запись движения пишет только элементы управления, представленные в компактном списке трекера;
параметры операторов записываются только для оператора 1. Остальные назначения модуляции
продолжают работать вживую, но не порождают команды фразы.

`SCP` и `SCT` сохраняют отображение в байтовом масштабе на регистры SID шире 8 бит.
`SMR 01-C8`, `SWV 01-08` и `SPR 01-10` теперь соответствуют родной нумерации пресетов.
Показываемые значения пресета - базовые настройки, не зависящие от играющей огибающей
или LFO. `SLE` работает с уровнями операторов и прямыми параметрами FM, не
перезапуская ноту и не меняя сохранённый патч.

У всех нативных FX есть описательные заголовки, диапазоны и описание поведения в селекторе FX
фразы, а также подсказки по значениям. `CMD` описывает тон/шум, duty или ширину шума
в зависимости от выбранного инструмента. Эти элементы управления дополняют общие группы Track,
Envelope и Modulation; одна группа движка не составляет полного
набора доступных FX фразы.

Существующие общие фильтры LP/BP/HP в Braids, Plaits, PCM и других поддерживаемых
движках - это программная обработка после синтеза. aChChid вместо этого использует свой родной
тракт фильтра 303. В этом раунде ни AY, ни нативный FM не получают фильтра; яркость меняет
сам синтез FM. Вставки дорожки остаются доступны для дополнительной обработки.

Нативные инструменты сохраняются в CNI версии 7 (8, когда есть абсолютные команды),
а нативные песни - в CCT версии 9. Инструменты с импортированными последовательностями
используют CNI версии 9, а песни с ними - CCT версии 10. Старые сборки
не могут открывать эти более новые файлы с последовательностями. Сохранённые байты пресетов FM и
настройки тембра на странице инструмента остаются без изменений.

### Нагрузка на портативные консоли для встроенных чипов

В песне восемь дорожек и **два слота эффектов-вставок на дорожку**. Шестнадцать
доступных слотов не гарантируют достаточно CPU для шестнадцати эффектов.
Предел DX7 в шестнадцать активных нот - отдельный бюджет синтеза на всю песню;
аккорды и хвосты release в него входят.

В измерениях на R36H четыре зацикленные дорожки WAV, Sega PSG, GB Pulse, DX7 и
OPL3 с общими отправками и четырьмя вставками (два Compressor, Doubler, TAPESCAM)
показали себя лучше, чем плотные восьмидорожечные аранжировки FM. Версия с одной нотой
не имела пропусков дедлайна рендеринга в тридцатисекундном измерении 48 kHz/512 кадров;
добавление четырёхнотного аккорда DX7 дало один скачок тайминга. Плотные песни FM
со множеством дорогих вставок превысили бюджет CPU. Оставляйте запас,
следите за существующим индикатором перегрузки и добавляйте эффекты там, где они помогают песне.
Приложение сохраняет каждую дорожку и каждый слот; нового жёсткого ограничения на число вставок нет.
Полные измерения и состояние длительных тестов см. в `chip-instruments-report.md`.

Соответствующий 70-секундный физический аудиотест этой сбалансированной аккордовой аранжировки
прошёл без пропусков дедлайна рендеринга и без зарегистрированных опустошений буфера ALSA при существующей
настройке 48 kHz / 4906 кадров. Худший callback длился 81,819 мс при дедлайне
102,208 мс. Тесты использовали отдельное мастер-усиление 0,4 для запаса.
Сохраните маршрут напрямую к карте у штатного лаунчера, `AUDIODEV=plughw:0,0`: общий
микшер системы по умолчанию давал опустошения буфера в диагностических пробах. Ни одна
пользовательская настройка звука не менялась. Десятиминутный стресс-тест с меньшим буфером всё же зафиксировал
28 скачков тайминга; полные результаты приведены в отчёте.

### Инструменты SID и FX фраз

Выберите **CHIP → SID**. Bank предлагает **ChooChoo SID Originals** (32 авторские
программы) и **SIDkit Effects** (24 эффекта под лицензией MIT). Обе используют один и тот же
браузер пресетов и сохраняют выбранную программу целиком внутри инструмента
и песни. Для передачи песни внешний банк не нужен. Это нативные
программы параметров SID с огибающими и рецептами движения, а не сэмплированный звук и не
готовые песни C64. Отдельные двенадцать исследовательских кандидатов GoatTracker
не поставляются; их таблицы wave/pulse/filter требуют отдельного импортёра/плеера.

Страница инструмента предоставляет форму волны/ширину импульса, режим фильтра/частоту среза/резонанс
и родные элементы управления ADSR. SID использует зафиксированные по версии цифровой осциллятор,
огибающую и пошаговый (по циклам) фильтр в стиле 6581 из floooh/chips. Альтернативных моделей чипа,
выбора ревизий и добавленных профилей характера нет. Это обобщённое приближение,
а не откалиброванная аналоговая модель R2/R3/R4/8580.

У каждой ноты свой фильтр. Ring/sync используют молчащий осциллятор-партнёр, поэтому
совместное использование фильтра и трёхголосные взаимодействия отличаются от настоящего SID.
У портативной консоли общий на песню бюджет из четырёх обычных нот SID.
Ring или sync стоит две единицы бюджета на ноту, что допускает две такие ноты или одну плюс две
обычные. Аккорды и хвосты release учитываются. Отпущенные ноты снимаются
первыми; новые ноты имеют приоритет над более старыми удерживаемыми. Дорогие вставки и
другие синтезаторы по-прежнему делят бюджет аудио-CPU.

| FX | Диапазон | Действие |
| --- | --- | --- |
| `SCP` | `00-FF` | База ширины импульса, масштабируется до родной 12-битной ширины; движение pulse по рецепту остаётся активным. |
| `SCT` | `00-FF` | База частоты среза, масштабируется до родной 11-битной частоты среза; движение фильтра по рецепту остаётся активным. |
| `SRN` | `00-0F` | Родной резонанс. |
| `SWV` | `00-07` | Triangle, saw, tri+saw, pulse, tri+pulse, saw+pulse, tri+saw+pulse, noise. |
| `SFI` | `00-07` | Биты режима фильтра: 1 низких частот, 2 полосовой, 4 высоких частот; 0 bypass. |
| `SMR` | `00-FF` | Тактовая частота макроса рецепта, масштабируется от 1 до 200 Hz. |
| `SRG` | `00-01` | Треугольная кольцевая модуляция с молчащим партнёром. |
| `SSY` | `00-01` | Синхронизация осциллятора с молчащим партнёром. |

Ширина импульса и частота среза поддерживают `SLE`. Дискретные волновые формы, переключатели, резонанс
и обратная связь FM сохраняют свои полезные родные шаги; более широкие значения байта не
создали бы больше аппаратных состояний. `FBK` напрямую выбирает feedback `00-07`.
Уровни операторов используют диапазоны, специфичные для движка и перечисленные выше. Регулировки яркости и
мастера сохраняют полный диапазон байта.

### Переносимые заводские коллекции и пресеты USER

Инструменты встроенных чипов используют **Bank:** для выбора ALL, включённой коллекции или
USER. **Preset:** выбирает звук внутри этой выборки. Удерживайте EDIT и нажимайте
Влево или Вправо на любой из строк, чтобы перебирать; короткое касание EDIT открывает её селектор.

Включённые коллекции - это ZIP-пакеты в `instruments/FACTORY/`. Файлы USER кладутся
в `instruments/USER/<engine>/`: `dx7`, `opll`, `vrc7`, `opl2`, `opl3`,
`genesis`, `arcade`, `sid`, `sega`, `gb-pulse` или `gb-noise`.
Просматривайте свои папки напрямую или кладите туда ZIP с папками и совместимыми пресетами
`.cni`. DX7 также принимает поддерживаемые `.syx` с одиночными голосами и банками по 32 голоса,
в том числе внутри ZIP. ZIP остаются нетронутыми на диске. Прямая загрузка WOPL/WOPLX не поддерживается;
используйте совместимые пресеты CNI или сначала преобразуйте поддерживаемые исходные форматы офлайн.

Перебор пресетов USER продолжается через файлы, папки, банки и ZIP-пакеты в
обоих направлениях и замыкается на концах. Повторное открытие браузера USER следует
текущему выбору. ALL включает звуки USER в Unsorted для движков
с категориями; USER остаётся отдельным выбором верхнего уровня. Sega PSG и Game Boy используют
плоские списки ALL/Factory и иерархический браузер USER, без панели
Unsorted. Старые файлы DX7 в `instruments/banks/dx7/` остаются доступными в USER.

Движок показывает только совместимые включённые коллекции. Factory Presets
объединяет включённые наборы тембров OPLL/VRC7 для выбранного движка; DX7 объединяет
оригиналы ChooChoo и YSE. Скачанные именованные коллекции остаются отдельными.
Fat Man 2-op указан в OPL2, а Fat Man 4-op - в OPL3. Совместимые файлы
CNI для OPL2 по-прежнему можно использовать в папках USER для OPL3.

Выход встроенных движков использует фиксированную измеренную компенсацию усиления, а не
нормализацию по пресетам. Поэтому существующие песни на встроенных инструментах могут звучать
на другом уровне; проверьте баланс сохранённых миксов. Метод калибровки
и границы описаны в `scripts/README_MEASURE.md`.
